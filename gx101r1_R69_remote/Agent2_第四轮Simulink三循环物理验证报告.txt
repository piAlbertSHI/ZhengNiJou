8. Self-rework record
Initial Simulink MATLAB Function code generation could not infer the 773-column variable-size audit vector robustly, so the model was rebuilt with an Interpreted MATLAB Function block driven by the Simulink clock.
Early SE phase kinetics did not load/unload across the intended stage windows; the phase driving terms and stage targets were adjusted and revalidated in Simulink.
The mechanical solver now records Eq.6/Eq.7 residuals on every sample. Eq.6 is tight by construction; Eq.7 transient residual is reported separately from endpoint residual because the simplified stress command is event-driven in this first full-cycle Simulink prototype.
