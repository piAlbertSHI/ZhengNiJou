五、失败原因定位

当前失败阶段：

    步骤 3：支路单元预检

失败表现：

    单支路 0.02 s Simscape 仿真超过任务书 120 s wall-time 门槛。

已经排除：

1. 不是第六轮模型缺少四个角色支路。
2. 不是缺少支路探针。
3. 不是 `solver_T_init_101_internal` 参数缺失；该问题已修复。
4. 不是机械本构核退化；离线预检已出现非零应力和相变方向。

最可能原因：

1. 第六轮当前把每个角色支路复制为完整 mature solver101 loop；即使逐支路 comment out，单个完整 loop 仍包含 101 节点固体、双流体路径、完整 PI/阀/热端/冷端网络和多个 solver configuration。
2. 这种“完整 loop 作为 branch unit”的粒度仍然过重，不满足任务书的 0.02 s / 120 s 支路单元预检门槛。
3. 第六轮需要进一步裁剪每个 role branch，只保留该角色所需的单条成熟流体路径、对应 buffer/HX/valve/Pressure PI/flow sensor/temperature probes，而不是复制完整双路径 mature loop。

六、下一步最小修复

下一步不能继续运行循环。最小修复是重构 branch unit 粒度：

1. 从 mature loop 中提取单支路模板：
   - hold path template: V1/V2/V3 + HoldPipe_001..051 + 对应 buffer/HX/probes/PI；
   - cooldown path template: V4/V5/V6 + CooldownPipe_001..051 + 对应 buffer/HX/probes/PI。
2. 为 `SMA_SHEX`、`SMA_THE`、`SE_THE`、`SE_RHE` 各生成单路径支路，而不是完整双路径 loop。
3. 每条支路只保留一个 solver configuration 和必要 thermal-liquid settings。
4. 先只构建一个 branch unit 最小复现模型，确认 0.02 s < 120 s。
5. 单支路通过后再复制成四角色支路。
