# SMA-SE 长循环效率优化与稳态续算报告

## 1. 报告状态

本报告对应唯一生产模型
`gx101r1_R69_remote/heatdrive_ecc_coupled_se21.slx`。正式长循环当前仍在运行，
本节不预写稳态结论。最终结果必须来自
`outputs/qian_coupled_accel_steady_20260816` 内的原始 MAT、Operating Point、
进度 CSV 和验证报告。

## 2. 已保留结果与续算边界

以下结果均保留，不覆盖：

1. 当前 ODE3、轴向体积、路线独立 PI 的 1-cycle/3-cycle 机制回归；
2. 2026-08-13 的旧 20-cycle 至 160-cycle 检查点链；
3. 本轮 normal/accelerator A/B 和 cycle-1/cycle-2 Operating Point 回归。

旧 20-cycle 不能直接接到当前代码。其检查点合同缺少当前
`se_buffer_volume_m3`、显式一维轴向固体体积、Bogacki-Shampine ODE3 本构子步
和 Stage 2/4 路线独立 PI。生产 runner 会以
`Run:EighthRound:CheckpointContractMismatch` 拒绝这种跨合同恢复。强行绕过会把
不同物理模型拼成一条时间线，因此本轮从当前代码重新生成 fresh 20-cycle，之后
才用当前 Operating Point 继续 40、60 等分段。

## 3. 效率优化

采用的优化仅改变执行方式和冗余日志，不改变数值模型：

1. `SimulationMode` 从 normal 改为 accelerator；
2. 关闭未使用的顶层 `tout`、`yout` 和 Signal Logging；
3. 保留全部生产 To Workspace 信号、21+21 节点状态和探针；
4. 中间分段不生成 PNG，最终停止后统一生成图集；
5. 固定 1 ms ODE3、1 ms Simscape local solver、阀泵命令和热力学参数不变。

一循环 A/B 使用 10001 个时间点、59 个物理字段和 72 个探针。全部数值数组
`maxabs=0`，证明 accelerator 与 normal 在本模型上位级一致。物理段 walltime
由 `277.557765 s` 降为 `248.696172 s`，单次实测加速比为 `1.116052`。

## 4. Operating Point 严格验证

Accelerator 能保存并恢复 Simscape Operating Point。cycle 1 保存后续算 cycle 2，
与一次连续 3-cycle 基线比较：

- `10.001 < t < 20 s` 的 SMA/SE 温度、相分数、应力、应变、热源、流量、
  压力和端点热容全部位级一致；
- 检查点内部边界 `t=10 s` 经拼接修正后位级一致；
- 有限 2-cycle 的最终 `t=20 s` 按 Stage 4 终点定义，而更长连续运行同一时刻
  已进入下一 Stage 1。该终止样本定义差异不代表状态丢失；下一段恢复时会由新段
  边界样本替换。

MATLAB 对 `ECC_Constitutive21_VectorStep` 给出“持久变量不参与 Operating Point”
警告。本构权威状态存放在外部 Unit Delay；上述内部区间位级比较证明该警告没有
导致生产状态丢失。警告保留，不屏蔽。

## 5. 正式长循环设置

- 输出根：`outputs/qian_coupled_accel_steady_20260816`
- Git 代码：`1840737 Add verified accelerated steady continuation`
- 分段：每 20 cycles
- 最大：200 cycles
- 每段保存：原始 MAT、验证报告、Operating Point、进度 CSV
- 监测：每半小时检查 stdout、stderr、PID、CPU、门禁和漂移
- 机制失败：立即停止，不继续传播错误状态

严格周期稳态要求最后十循环同时满足：

- endpoint drift `<= 0.05 K`；
- same-phase full-temperature drift `<= 0.05 K`；
- same-phase phase-fraction drift `<= 1e-4`；
- 所有流路、压力、液体物性、相变、兼容和能量门禁通过。

近稳态停止要求连续两个 20-cycle 分段同时满足：

- endpoint drift `<= 0.10 K`；
- same-phase full-temperature drift `<= 0.10 K`；
- same-phase phase-fraction drift `<= 2e-4`。

近稳态只表示可停止长时间计算进行模型诊断，不等于 Table 4 定量复现。

## 7. 长循环结束后的后续主线

### 7.1 若达到严格周期稳态

1. 用最终十循环重绘 SCI 图，不混入冷启动周期；
2. 连续三个十循环窗口计算 Qian Eq. (9)，检查统计稳定性；
3. 将无负载稳态温跨与 Table 4 的 26.2 K 比较，但同时报告参数闭合不确定性；
4. 独立施加真实 CHEX 冷负载，以 Eq. (9) 十循环均值搜索零温跨；
5. 用真实入口/出口温度、质量流量和 cp 按 Eq. (10) 计算 SCP，与 0.64 W/g
   比较，禁止向结果写入目标值。

### 7.2 若只达到近稳态

1. 不直接做 Table 4 最终比较；
2. 分解 endpoint、完整温度场和相分数三类剩余漂移；
3. 判断慢变量来自端点热容、连接管库存、PI 积分记忆还是局部相变前沿；
4. 只有存在文献或守恒依据时才修改参数，然后从已验证检查点做敏感性分支。

### 7.3 若机制门禁失败

1. 保留失败前最后一个通过的 Operating Point；
2. 按节点绘制应力-温度-相分数和正/逆相变过驱量；
3. 定位首先失效的节点、阶段和流路；
4. 禁止端点赋值、温度回写、相分数强制或按 26.2 K 反标；
5. 单节点、21 节点绝热/等温和一个完整半周期重新通过后才恢复长循环。

### 7.4 系统级论文验收

1. 建立 SHEX 输入、HHEX 排热、CHEX 冷量、SMA/SE 储能、泵功、热漏和内部
   机械功抵消的闭式能量平衡；
2. 分开材料级、部件级和系统级 COP/SCP；
3. 完成节点数、时间步、流体浓度、端点热容、UA 和管路库存敏感性；
4. 最终交付原始 MAT、Operating Point、固定 50 点探针、图集、运行哈希、
   周期漂移和两个 Table 4 独立工况。
