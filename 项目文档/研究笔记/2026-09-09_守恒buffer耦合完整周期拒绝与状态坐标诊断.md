## 4. 失败定位与可验证推断

入口、出口连接腔首个超过 1e-8 J 的单步能量缺口分别在 0.108 s、0.101 s。
全周期分别有 9046、9077 个单步超过该阈值；大的跳变集中于约 5.1 s 的迅速降温。
实际 stored_mass 与 V*rho、stored_energy 与 M*u 的别名仍在原门限内，故不是简单记录字段接错。

对实际双线性 rho(T,p)、u(T,p) 表直接计算右端雅可比，独立核对：

```text
dM_right = V*(rho_T*dT + rho_p*dp)
dU_right = M_right*(u_T*dT + u_p*dp) + u_right*dM_right
```

入口/出口端口积分与该微分增量的最大单步差仅
`3.77654e-12 / 6.33982e-12 J`，质量差 `7.36919e-19 / 1.15366e-18 kg`。
但与实际端点库存增量不符。这说明不能把雅可比微分式离散账当成真实库存端点守恒。

**推断而非已确认编译事实：** Simscape 符号约简可能选择了 T,p 微分坐标，
即使组件源码声明 `der(stored_mass)` 和 `der(stored_energy)`，也不能保证其成为实际积分坐标。
本次尚未导出编译后的状态选择信息。下一步必须读取实际编译状态，再设计保持 M/U 状态坐标的独立修正并做受控试验。
不能使用补偿热源、重置状态、跳过切换样本或放宽端点门限来消除该缺口。
