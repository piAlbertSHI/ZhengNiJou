## 4. buffer 残差为何不能被“方程通过”覆盖

对恒压 Tank，以原生 `h_I`、`mass`、`T_I` 和实际物性表的 `cp` 计算严格离散乘积恒等式：

```text
sum(M_n*cp_n*dT + h_n*dM) - Delta(M*h)
  = sum(M_n*(cp_n*dT-dh)) + sum(dM*dh)
```

右侧第一项是比热积分与原生焓割线的差异，第二项是 BE 离散乘积项。
这只是残差来源拆分，不是待补充的物理热源，也没有从结果反拟合任何系数。

保守臂四个 buffer 合计：

| 分项 | J |
| --- | ---: |
| 既有独立诊断的 1 mm 附加热容系数积分 | +0.00488050552 |
| 负压头输运项 | -0.00015426470 |
| cp 积分与 h 割线差异 | -0.06288267817 |
| 离散乘积项 | +0.00002403408 |
| 物理端点残差 | -0.05813240270 |

附加热容/压头解释后，各 Tank 的离散方程区间残差在既有浮点容差内。
但 `cp*dT` 与 `dh` 的差异仍然保留，不能把方程系数积分换名为真实 `Delta(Mu)` 后宣称整机闭合。
下一步应在独立 Tank 试验中区分物性表热力学一致性、有限步离散效应与附加热容模型，不能直接加一个残差补偿热源。
