# OP 接口隔离试验与迁移边界

日期：2026-09-08。此文件补充第四十二阶段报告，不修改其冻结证据。

## 1. 本次实际完成了什么

在本机 MATLAB R2025b 中构建一个独立的热容与积分器模型，验证公开 OP 状态写入是否实际影响续算。
模型只有 1 kg、1000 J/(kg K) 热容，独立积分器输入为零，初始记忆为 7.25。
使用 accelerator、ode3、1 ms 步长及局部 Backward Euler；完整 OP 的两项 checksum 检查均为 error。
未加载生产模型或生产检查点，未修改 C200，未生成生产恢复点。

两次程序均只启动一次并自然退出 0；退出 0 表示收集完整，不表示每一试验臂都仿真成功。

## 2. 结果及逐项解释

先分别生成 340 K 与 400 K 两个隔离热态种子，时间均为 2000 到 2000.001 s。
随后从低温完整 OP 续算至 2000.002 s。下表列出的结果均来自实际输出，不仅是赋值读回。

| 试验臂 | 单独改变什么 | 实际结果 | 允许的结论 |
|---|---|---|---|
| baseline | 不变 | 温度 [340,340] K，记忆 [7.25,7.25] | 原样恢复对照通过 |
| conflicting_simscape_target | 初始化目标 340 改为 400 K，完整 OP 不变 | 严格恢复拒绝，无续算轨迹 | 本次不能据此判断两类 OP 的运行时优先级 |
| builtin_memory_edit | 积分器公开状态 7.25 改为 8.25，目标仍为 340 K | 温度 [340,340] K，记忆 [8.25,8.25] | 此普通状态写入生效 |
| whole_solver_group_copy | 从高温种子复制完整命名求解器状态组，目标仍为 340 K | 温度 [400,400] K，记忆 [7.25,7.25] | 此隔离模型的整组状态复制实际改变温度 |

这里没有解释或修改匿名打包索引，没有访问私有 OP 字段。此模型只有一个热容状态；
不能推导多物理网络全部状态、执行历史及隐含状态均可迁移。

第一版存在混杂因素：除 baseline 外三个臂都同时更改了初始化目标，因此两个状态修改臂也在
续算前被拒绝。第一版不用于判断状态写入是否生效，原始 JSON 与日志原样保留。
修正版只让 conflicting_simscape_target 臂改变目标，排除了这个混杂因素。

## 3. 与 C200 证据如何区分

- 严格原样 C200 完整 OP 续算及 Dataset 原值写回对照，均初始/一步后 1474 组逐位一致。
- 历史复杂模型公开 72 组或 73 组复制，仍初始 7 组、一步后 197 组超限，两臂输出相同。
- 本次单热容正对照不能推翻复杂模型的失败，也不能证明复杂网络的公开求解器记录一律无效。
- 整机物理终点库存残差仍约 -1.406 J；当前没有合格的结构迁移恢复点，成对 Table 4 未完成。

因此不再使用“所有公开状态写入都会被忽略”或“求解器整组复制必定无效”这类过宽判断。
下一次复杂模型试验必须有新的可检验假设，并保留原样完整 OP 正对照、全观测比较及原有严格门禁。
未经额外授权，不另起替代 C200 的冷态生产链。

## 4. 官方接口说明与证据边界

2026-09-08 查阅的 MathWorks 当前在线文档说明：ModelOperatingPoint 含 Simscape 恢复数据，
但不开放其中的 Simscape operating-point data 修改；同时配置两类 OP 时，模型 OP 优先。
这描述的是支持的接口合同，不能由本次标量正对照外推为复杂模型迁移资格。
[官方恢复与 Simscape 限制说明](https://www.mathworks.com/help/simulink/ug/model-operating-point-for-faster-simulation.html)

`.get` 用于 Stateflow、MATLAB System 及 S-function 等对象，不是普通积分器状态访问入口；
早期针对积分器调用 `.get` 的 CannotFind 不能证明积分器状态不可读取或修改。
[官方 ModelOperatingPoint.get 说明](https://www.mathworks.com/help/simulink/slref/simulink.op.modeloperatingpoint.get.html)

在线页面不是锁定的 R2025b 文档快照；本报告明确区分当前官方说明与本机 R2025b 实测。
本次目标冲突臂在严格恢复检查处被拒绝，未实测通过冲突初始化来证明优先级，也未降低检查等级。
