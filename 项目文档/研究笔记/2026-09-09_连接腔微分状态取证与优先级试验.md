### 16.1 实际依赖改变了实现路线

新增只读导出器 `Inspect_HeatDriveECC_SMADerivativeContract.m`，重建当前模型后递归追溯控制器上游。

真实链路是：
`流量目标 + 带符号实测流量 -> ErrorNormalizer -> ErrorLag -> Kp/Ki`。
因此不能把 Kp/Ki 的输入误认为原始流量误差，并要求另加滤波或对流量做数值差分。
实际参数为：

| 参数 | 实际值 |
|---|---:|
| 归一化 Gain | 1 |
| ErrorLag 传递函数 | `1/(0.002 s + 1)` |
| Kp / Ki | -0.6 / -10 |
| 积分下限 / 上限 | -0.14733718599999998 / 0.1 MPa |
| 压力下限 / 上限 | -0.35 / 0.02 MPa |
| 积分复位 | level，内部初值 0，限幅开启 |

归一化增益的维度和 Kp/Ki 的数值含义必须跟随实际 Simulink 信号定义，不凭参数名推断未经验证的归一化尺度。

### 16.2 可执行导数计算核

新增 `Evaluate_HeatDriveECC_SMADerivative.m`，只计算导数，不改变控制状态、原压力值路径或滤波参数。
在无跳变的开区间上，令 x 为已有滞后输出、e 为归一化误差、I 为原积分器输出、g 为 enable：

```text
dx/dt = (e - x) / 0.002
dI/dt = Ki*x，复位保持或积分限幅阻止继续越界时取 0
p_raw = g*Kp*x + I + bias
dp_raw/dt = g*Kp*dx/dt + dI/dt + dbias/dt
p = clip(p_raw, p_min, p_max)
```

压力在限幅外的导数为零；恰在限幅边界时按向内/向外的右导数处理。
没有增加新的滤波器，没有把 0.002 s 调小，没有用有限差分替代误差环节的原 ODE。
此核**尚未接入耦合模型**，不能仅凭公式或单元测试宣称模型接口通过。
