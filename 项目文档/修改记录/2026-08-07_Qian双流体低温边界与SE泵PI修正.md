# Qian 双流体低温边界与 SE 泵 PI 修正

## 触发证据

当前 Fig.5 正驱动力版本的 60-cycle 无负载连续 Simscape 运行完成于
`outputs/qian2019_no_load_long/qian2019_table2_table4_simscape_60cycle_20260807_143352`。
机理检查通过，但最后十循环仍有 `0.2299 K` 端点漂移、`0.4840 K` 同相位温度
漂移和 `0.02518` 同相位相分数漂移，因此 `periodic_steady_state=0`。Eq. (9) 的
`15.9348 K` 仍是瞬态值。

随后启动的 150-cycle 任务在仿真时间 `818.789 s` 被人工终止。此时 SE 内部
`HoldPipe_019/020` 已低于原 Thermal Liquid 表的 `273.16 K` 下限。该下限来自
水侧表，却被错误复用于 Qian 明确规定的 SE glycol-water 侧。

## glycol-water 闭合

Qian 2019 Table 2 只给出 `glycol-water`，未给浓度。旧 30 vol% 丙二醇闭合的
冻结点约为 `-12.7 degC`，无法给 SE 的 `TMs=-15 degC` 留出工作裕量。生产闭合
改为 40 vol% inhibited propylene-glycol/water：

- Dow DOWFROST HD 官方表给出冻结点 `-21.1 degC`；按其 3 K 运行裕量建议，
  最低运行温度取 `255.05 K (-18.1 degC)`，低于 SE `TMs` 约 3.1 K。
- 在 `303.15 K` 参考温度处，40 vol% 表插值得到
  `rho=1044.973333 kg/m3`、`cp=3638 J/(kg K)`、
  `k=0.407866667 W/(m K)`、`mu=0.00330735934 Pa s`。
- SE Thermal Liquid 使用 `255.05-393.15 K` 的独立温变表；SMA 水侧继续使用
  IAPWS `273.16-413.16 K`。两个域的内部越界动作均由 `warn` 升为 `error`。
- HHEX/CHEX 的 0.1 kg 附件储液闭合随新 `cp` 一致变为 `363.8 J/K`。

官方物性来源：Dow, DOWFROST HD Technical Data Sheet,
https://www.dow.com/documents/180/180-01315-01-dowfrost-hd-tds.pdf

该浓度是 Qian 未报告参数的显式工程闭合，不宣称是论文给定值。

## 泵控制修正

40 vol% glycol 的冷态黏度揭露了旧 SE PI 的两个问题：

1. SMA 和 SE 共用同一个压力饱和下限。现拆分为 SMA `-0.35 MPa`、SE
   `-0.40 MPa`，不再为 glycol 冷路改动水路控制器。
2. SE Integrator 的遗留上下限仅为 `+/-0.005 MPa`。真实 Stage 4 流量低于
   目标时，积分器立即饱和，增大 `Ki` 不产生任何作用。新下限由层流
   `delta_p proportional to mu*m_dot` 和 Table 4 冷端 `276.95 K` 的 Dow 黏度
   计算，为 `-0.21819047 MPa`；上限为 `+0.10 MPa`，总泵命令仍受
   `[-0.40,0.02] MPa` 饱和约束，并在非 Stage 2/4 时复位。

最终 SE 增益为 `Kp=-35 MPa/(kg/s)`、`Ki=-120 MPa/(kg/s s)`。流量来自真实
Simscape 传感器闭环，不写入或覆盖任何结果。

## SMA 换向零流量焓奇点

当前物性与 PI 版本第一次 100-cycle 无负载运行没有卡死，而是在 `t=110.05 s` 被水侧
`413.16 K` 上限硬断言终止。随后完成的 11-cycle 边界诊断表明，SMA 固体最高温度仍低于
`393 K`，超温只发生在共用泵出口邻接的 Hold/Cooldown 首端流体节点。旧代码在换向时把
SMA 压差硬编码为恰好 `0 Pa`；SE 却已使用 `-1 Pa` 定向预压来避免零流量时上风焓不定。

第一步曾让 SMA 与 SE 一致使用参数化的 `-1 Pa` 换向预压。相同 11-cycle 连续 Simscape
回归中高温尖峰消失，但后续 100-cycle 任务在 `t=430.05 s` 再次于同一歧管出现低温焓奇点。
因此 `-1 Pa` 只延迟失稳，不构成长周期闭合，已被拒绝。

最终把 SMA/SE 换向预压拆分：SE 保留已经验证的 `-1 Pa`；SMA 取 Qian 几何层流两条路线
较小主压降的 `0.1%`，即 `-0.000149911704742 MPa`。该压差在真实 11-cycle 日志中形成约
`0.0772 g/s` 的定向换向流，仅为 `50.8 g/s` 主流量的约 `0.152%`。十个循环边界的泵出口
温度稳定在约 `306.09-306.17 K`，Cooldown/ Hold 泵侧约为 `305.99-306.07 K` /
`335.22-335.28 K`，全体探针范围为 `287.06-393.15 K`。

验收器的两个硬门继续保留：一是从真实压力日志检查每个 SMA 路由换向中点确实观察到
SMA 专用定向预压；二是检查泵出口、Hold 泵侧和 Cooldown 泵侧探针不超过源温 `2 K`。
该修复没有扩大物性范围、修改热容或覆盖任何温度结果。

## Qian connecting pipe 有限体积闭合

`0.1%` 定向换向压力虽然越过旧失稳点，但 100-cycle 任务仍在 `t=465.076 s` 的
Stage 2→3 换向处触发 SHEX/V1 热端焓奇点。这证明单纯提高预压只能移动零容积歧管的
奇点，不能形成长期守恒状态。

Qian 2019 Table 2 已给出 connecting HTF pipe 的直径 `3.2 mm` 和长度 `0.2 m`，旧代码却
明确标为 `reference_extracted_not_mapped`。现把该文献库存映射为 SMA 泵入口和出口各一个
两端口 Constant Volume Chamber，每个体积为
`pi*(3.2e-3)^2/4*0.2 = 1.60849543864e-6 m3`。两腔是实际流路串联状态，不是温度源；H 端
未连接，表示绝热。现有物理压力-流量前馈已包含附件路线损失，因此恒容腔采用理想混合、
不重复增加经验压降。

唯一主模型 `heatdrive_ecc_coupled_se21.slx` 已实际保存这两个部件。构建器硬审计同时检查
块类型、文献体积/面积掩码、低优先级初值、A/B 串联拓扑、H 端绝热以及不存在绕过恒容腔
的泵直连。保存后重新加载、编译和审计均通过。
