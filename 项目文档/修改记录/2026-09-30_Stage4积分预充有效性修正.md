# Stage4 积分预充有效性修正

日期：2026-09-30

## 发现

对 `precharge50_kp225_wired_20260930_10s_v2` 的执行路径复核发现，阀门压力预充已经接线，
但积分预充使用了固定网格上的二值 `stage4_activity_gate`。因此条件
`0 < activity < 1` 永远不成立，`se_stage4_commutation_precharge_fraction=0.5` 没有真正进入
积分器使能信号。此前仅凭 v2 结果判定“预充电没有改善”是不成立的，已撤回该归因。

## 修正

- 在固定仿真网格上插值连续阀门开度 `mean(se_values(:,4:6),2)`；积分预充只在开阀过渡的
  `0 < activity < 1` 区间生效。
- 冷态 runner 将 `SE_stage4_pressure_integrator_enable_command` 写入 configuration contract。
- 当请求非零预充但没有任何 `(0,1)` 门控样本时，runner 在 MATLAB 仿真前立即失败，禁止产生
  看似有效但参数未生效的长结果。
- 默认预充比例为 `0`，生产主线行为不变；本修正仅作用于隔离冷态诊断。

对应代码提交：`c7f46db`（隔离 worktree）、`3181689`（主线）。此前 v2 结果仍保留为诊断，
但不再用于判断积分预充的因果效果，也不进入 20-cycle。
