# SMA 换向长循环失效与平滑泵压修正

## 失效事实

- 真实 Simscape 冷启动 150 循环任务在 `t = 1395.101 s` 失败，即第 140 循环 Stage 2 转 Stage 3 后 `0.101 s`。
- Simscape 报告 `SMA/HoldPipe_021` 与 `SMA_V3_pump_to_heat_path` 端口温度超过水物性表上限 `413.16 K`。
- 失败任务未完成，未生成最终 Operating Point，因此没有把失败状态伪装成可续算结果。
- 130 循环原始 1 ms 日志显示正常循环最高流体温度约 `393.15 K`，切换前水侧压力约 `0.76-1.01 MPa`，不存在真实高温或高压逐渐逼近物性上限的过程。

## 原因审计

旧换向逻辑在 0.15 s 内依次执行降压、先关后开阀门、恢复工作压。工作压恢复段使用线性斜坡。第一个 1 ms 求解步的泵压命令约为 `-4.05 kPa`，对应瞬时 SMA 流量约 `1.95 g/s`。故障时间恰好位于新路线阀门打开后、工作压恢复的第一个求解步。

Git 历史中的 `81efe8e` 已针对第 40 循环同类故障加入开环降压和对数热开关，但该处理只把故障推迟到第 140 循环，没有消除工作压斜率在 ODE3 离散网格上的首步激励。

## 修改

- 不改变唯一主模型 `heatdrive_ecc_coupled_se21.slx`。
- 不改变四阶段时长、阀门数量、先关后开拓扑、目标质量流量、稳态工作压或本构方程。
- 仅把新路线工作压恢复插值从线性函数 `f(r)=r` 改为零端点斜率三次函数 `f(r)=r^2(3-2r)`，其中 `r` 从 0 变到 1。
- 总换向时间仍为 0.15 s，恢复段末端仍精确到达原 Stage 1/3 工作压。
- 严格验收契约改名为 `finite_volume_break_before_make_smooth_pressure_log_thermal_ramp`，防止后续无意恢复旧逻辑。

## 短回归

静态命令验算中，恢复段首个命令节点由约 `-10.1 kPa` 降为 `-1.47 kPa`。真实 1 ms 日志在 `t = 5.101 s` 的插值泵压由 `-4.05 kPa` 降为 `-0.589 kPa`，瞬时流量由 `1.84 g/s` 降为 `0.268 g/s`。

一个完整 10 s 四阶段真实 Simscape 循环通过全部机构、流路、本构、温度域、压力、质量流量、能量守恒和探针硬检查。修复前后首循环 CHEX 温降只相差约 `0.00018 K`，说明修改局限在换向瞬态，没有重写热性能结果。

单循环只证明回归和机构正确，严格 Qian Table 4 复现仍标记为“未评估”。下一步必须用 Operating Point 每 20 循环分段推进，跨过原第 140 循环失效点并达到周期稳态后，才能评价 `26.2 K` 零负载温差。
