# SE 双作用活塞端点库存拓扑修复

## 问题定位

旧连续四阶段模型沿用了分阶段重启模板的同端 buffer 回流结构。Stage 2 和 Stage 4 各自在同一个 buffer 内闭合，不能在连续 `sim()` 中保存 Qian Fig.13 双作用活塞两腔之间的端点库存。旧 60 循环虽然机理检查通过，但冷、热 buffer 与 CHEX/HHEX 库存方向相反，因此该长循环性能结果失效。

## 模型修改

只修改唯一主模型 `gx101r1_R69_remote\heatdrive_ecc_coupled_se21.slx`：

- 删除 SE 侧旧公共吸入口歧管和多余公共 tank。
- 保留一个共享 21 节点 SE 再生床。
- 用两个 Pressure Source (TL) 表示 Qian Fig.13 同一个双作用活塞的两个液压面，两者共享同一 PI 压力命令，不解释为两台独立泵。
- Stage 2：冷腔/CHEX -> 活塞 Stage 2 液压面 -> V1 -> SE -> V3 -> HHEX -> V2 -> 热腔。
- Stage 4：热腔/HHEX -> 活塞 Stage 4 液压面 -> V4 -> SE -> V6 -> CHEX -> V5 -> 冷腔。
- 压力源使用既有负压差命令时，腔体必须接 `RConn1`，入口阀必须接 `LConn1`。首次连接反向导致真实倒流，现已交换两个压力源的液压端口。

构建器新增端口级拓扑审计。仅检查“模块相邻”不再足够，必须同时验证两条完整路由、共享命令、旧公共歧管不存在、两腔无短接和四个指定液压端口方向。

## 失败诊断证据

首次一循环诊断中，SE Stage 2/4 有符号流量为 `-3.6506/-3.6553 g/s`。Stage 2 末冷腔由约 `303.16 K` 升至 `317.85 K`，Stage 4 末热腔降至 `296.62 K`，证明是物理倒流，不是传感器符号差异。验证器没有被放宽，修复选择了交换压力源液压端口。

旧 60 循环 `qian2019_table2_table4_simscape_60cycle_20260807_022836` 也因此判为无效：其 Root ColdBuffer 约保持 `303 K`、Root HotBuffer 约降至 `292 K`，与 HHEX/CHEX 端点库存相反。

## 修复后一循环

权威结果：`outputs\diagnostic_piston_face_fixed_1cycle_20260807\qian2019_table2_table4_simscape_1cycle_20260807_031728`。

- 单次连续真实 Simscape `sim(sim_in)`，墙钟约 `266 s`。
- 机理硬检查通过。
- SE Stage 2/4 流量 `3.14935/3.15290 g/s`，相对 Qian `3.2 g/s` 低约 `1.6/1.5%`。
- 关闭支路泄漏约 `2.05e-8 kg/s`。
- Stage 2 热腔升至 `305.69 K`；Stage 4 冷腔降至 `301.40 K`，库存方向正确。
- SMA/SE 固体能量残差比例约 `0.193%/0.050%`。

## 修复后三循环

权威结果：`outputs\piston_inventory_fixed_3cycle_20260807\qian2019_table2_table4_simscape_3cycle_20260807_032643`。

- 单次连续真实 Simscape，墙钟约 `426 s`，全部机理硬检查通过。
- CHEX 三循环变化为 `-0.3873/-0.4283/-0.4324 K`；三循环末 HHEX/CHEX 为 `303.1784/301.9016 K`。
- Qian Eq.9 暂态温跨 `1.48681 K`，端点质量温跨 `1.27683 K`。
- Qian Eq.10 暂态比制冷量 `0.38942 W/g`。
- 周期稳态未通过：末两循环端点漂移 `0.49656 K`，同相位温度漂移 `2.04465 K`，相分数漂移 `0.0383521`。

以上三循环只证明连续流路、本构、探针和能量机制成立，不能宣称 Qian Table 4 复现。下一步必须先执行独立无负载长循环并用最后十个完整循环判稳，再执行独立零温跨负载工况。
