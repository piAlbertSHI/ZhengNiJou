【第六轮系统结构】

第六轮不能继续只把两条成熟支路重命名为四个物理角色。必须建立四个物理角色独立的流体支路实例：

1. `SMA_SHEX`
   - 作用：Stage1 废热源加热 SMA。
   - 热边界：`Th` 或论文废热源/PSC 热回收等效边界。
   - 能量：必须测量 `Q_SHEX_boundary`、`m_dot`、`T_in`、`T_out`。

2. `SMA_THE`
   - 作用：Stage3 环境热汇冷却 SMA。
   - 热边界：`T0` 环境热汇。
   - 能量：必须测量 SMA 向 THE 放热。

3. `SE_THE`
   - 作用：Stage2 SE 高载放热到环境热汇。
   - 热边界：`T0` 环境热汇。
   - 能量：必须测量 SE 向 THE 放热。

4. `SE_RHE`
   - 作用：Stage4 SE 低载从冷负载吸热。
   - 热边界：`Tc` 冷负载/RHE/CHEX。
   - 能量：必须测量冷负载向 SE 的热量。

这四条支路必须复制成熟部件或成熟同类部件来实现，包括 buffer、pipe、valve、Pressure PI、flow sensor、temperature sensor、thermal mass/HX。内部参数默认不变；若必须改参数，只允许改 51 节点 SMA/SE 固体接口、几何质量、导热、初始温度和阶段命令。任何成熟部件内部参数改动都必须有失败证据和最小修改说明。

【四阶段流路要求】

Stage 1：`sma_heat_load`

    SHEX 热源/热流体出口
      -> SMA_SHEX 泵/阀
      -> SMA actuator 51 节点换热通道
      -> SHEX 热流体入口
      -> SHEX 热源/缓冲液重新加热

必须满足：

- `m_dot_SMA_SHEX > closed_route_threshold`；
- `T_SMA_SHEX_in > T_SMA_SHEX_out`；
- `Q_SHEX_boundary > 0`；
- `mean(Ta)` 明显上升，不能只有 0.04 K；
- `xM_a` 从 1 下降；
- `xM_r` 从 0 上升；
- SE 流体支路关闭，SE 温升来自机械加载。

Stage 2：`se_reject_heat`

    THE/HHEX 环境侧流体出口
      -> SE_THE 泵/阀
      -> SE refrigerant 51 节点换热通道
      -> THE/HHEX 环境侧流体入口
      -> THE/HHEX 向 T0 环境放热

必须满足：

- `m_dot_SE_THE > closed_route_threshold`；
- 以进入 SE 为入口，`T_SE_THE_out > T_SE_THE_in`；
- `Q_SE_to_THE > 0`；
- `mean(Tr)` 从加载后的高温下降；
- SMA 支路关闭或高温滞留，不得伪造热流。

Stage 3：`sma_cool_unload`

    THE/HHEX 环境侧流体出口
      -> SMA_THE 泵/阀
      -> SMA actuator 51 节点换热通道
      -> THE/HHEX 环境侧流体入口
      -> THE/HHEX 向 T0 环境放热

必须满足：

- `m_dot_SMA_THE > closed_route_threshold`；
- `T_SMA_THE_out > T_SMA_THE_in`；
- `mean(Ta)` 下降；
- `xM_a` 上升；
- `xM_r` 下降；
- SE 流体支路关闭，SE 降温来自机械卸载。

Stage 4：`se_absorb_heat`

    RHE/CHEX 冷负载侧流体出口
      -> SE_RHE 泵/阀
      -> SE refrigerant 51 节点换热通道
      -> RHE/CHEX 冷负载侧流体入口
      -> RHE/CHEX 从冷负载补热

必须满足：

- `m_dot_SE_RHE > closed_route_threshold`；
- 以冷负载流体进入 SE 为入口，冷负载流体在 SE 中放热后出口温度降低；
- `Q_RHE_to_SE > 0`；
- `mean(Tr)` 从低温回升；
- SMA 支路关闭。

【本构和机械耦合要求】

1. 不允许继续让机械耦合停留在 `xM_a = 1`、`xM_r = 0` 的退化零载状态。
2. 必须参考论文 Eq.6-Eq.24 和 `d_2.slx` 中的本构求解核心，建立同一套应力用于：
   - Eq.6 force balance；
   - Eq.7 displacement compatibility；
   - SMA 相变驱动力；
   - SE 相变驱动力；
   - 应变和机械功计算。
3. 相分数必须由温度、应力、相变驱动力和时间积分推进，禁止使用 target phase fraction 直接指定。
4. Stage1 预期：
   - `xM_a` 从 1 降低，变化方向接近论文 `delta_xM_a`；
   - `xM_r` 从 0 增加；
   - 非零应力状态下 Eq.6/Eq.7 residual 通过。
5. Stage3 预期：
   - `xM_a` 回升；
   - `xM_r` 下降；
   - 卸载过程 Eq.6/Eq.7 residual 通过。
6. 若材料和几何组合导致 Eq.6/Eq.7 与相变条件不可同时满足，必须报告不可行原因，不允许强行截断或强行赋值。

【分层验证步骤】

第六轮必须按以下顺序推进，任何一步失败都要停止并返工。

步骤 1：第五轮失败复现和基线记录

- 运行或读取第五轮 1-cycle 失败结果；
- 记录 `SHEX_input_J = 0`、相变不动、能量残差和超时问题；
- 确认第六轮修复目标不是调图，而是消除这些失败。

步骤 2：四支路结构构建

- 复制成熟部件形成 `SMA_SHEX`、`SMA_THE`、`SE_THE`、`SE_RHE`；
- 每个支路建立独立入口、出口、内部、边界热流、流量探针；
- 输出支路语义表；
- 不接机械耦合前，模型应能编译。

步骤 3：支路单元预检

每条支路都要做：

- 固定固体温度；
- 运行 0.02 s；
- 运行 0.1 s；
- 运行对应 full-stage 时间；
- 检查流量、温差、边界热流符号、储能残差。

若 0.02 s 超过 120 s wall time 仍不返回，必须终止该测试并定位原因，不允许让 MATLAB 长时间空跑。

步骤 4：机械/本构离线预检

在不接 Simscape 流体前，用规定温度轨迹测试 `MechanicalCouplingSolver`：

- `Ta: 308 -> 340.412 K`，`Tr` 绝热加载；
- 检查 `xM_a` 下降、`xM_r` 上升；
- `Ta: 340.412 -> 308 K`，检查卸载；
- 输出 Eq.6/Eq.7 residual、sigma、epsilon、xM、潜热和机械功。

步骤 5：Stage1 物理闭合

- 只开启 `SMA_SHEX` 和机械耦合；
- 运行 0.02 s、0.1 s、full Stage1；
- 必须看到 SMA 明显升温、SHEX 输入、非零相变或接近相变启动条件；
- 若热量量级仍远低于论文，应优先修 SHEX 边界和流量，不允许继续跑循环。

步骤 6：Stage2/3/4 单阶段闭合

- Stage2 检查 SE 放热；
- Stage3 检查 SMA 冷却和 SE 卸载；
- Stage4 检查 SE 从冷端吸热；
- 每阶段都输出独立阶段能量表。

步骤 7：1-cycle 严格验证

- 四阶段连续运行一个 cycle；
- 不允许重置相分数或温度状态；
- 检查四阶段趋势和能量残差；
- 如果能量残差超过阈值，必须定位到具体支路或固体项。

步骤 8：3-cycle 验证

- 只有 1-cycle 通过后才能运行；
- 每阶段至少保存 50 个探针样本；
- 输出白底独立图，不要多图挤在一个难以阅读的图里。

步骤 9：10-cycle 稳定性检查

- 只有 3-cycle 通过后才能运行；
- 检查周期漂移、相分数漂移、热端/冷端储能漂移和能量闭合。
