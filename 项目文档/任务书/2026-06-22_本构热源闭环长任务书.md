## 物理阶段逻辑

执行者必须同时维护热流路和本构状态两条逻辑。

### Stage 1：SMA热驱动加载

- 流路：SHEX buffer -> 阀门 -> SMA侧PI泵 -> SMA 21节点 -> 阀门 -> SHEX换热 -> SHEX buffer。
- 热边界：SHEX必须代表文献中的热源侧，不得继续默认为`T0=308 K`。
- 本构：SMA从马氏体向奥氏体转变，产生SMA相变热和机械功；SE因耦合受力进入加载过程。
- 期望趋势：SMA温度上升并跨越相变驱动力区，`xM_a`下降，`sigma_a/sigma_r`非零且满足力平衡，`ECC_Q_SMA_constitutive_W`必须非零。

### Stage 2：SE向HHEX放热

- 流路：HHEX/THE侧流体经SE后回到HHEX/THE，延续当前右侧SE 24阶段成熟流路思想。
- 本构：原则上应是Stage 1后SE高温/加载状态向热端放热的换热阶段，不能无根据继续推进错误方向的相变。
- 执行者必须对照文献公式确认Stage 2是否应保持力学状态、缓慢演化、或只做热交换。若代码当前Stage 2无本构推进，应证明合理；若需要推进，必须来自文献公式。

### Stage 3：SMA冷却卸载

- 流路：HHEX buffer -> 阀门 -> SMA侧PI泵 -> SMA 21节点 -> 阀门 -> HHEX SMA独立分支 -> HHEX buffer。
- 本构：SMA从奥氏体向马氏体回转，SE发生卸载/逆过程。
- 期望趋势：SMA温度下降，`xM_a`上升，SE状态随耦合卸载，热源符号与Stage 1形成物理对应关系。

### Stage 4：SE从CHEX吸热

- 流路：CHEX -> SE -> CHEX，延续右侧SE成熟流路。
- 本构：原则上是SE制冷吸热阶段，必须对照文献公式确认是否继续发生相变或仅做热交换。
- 当前`HeatDriveECC_ConstitutiveCompatibilityStep51.m`中Stage 4仍推进SE卸载，这一点必须严查；如果与文献阶段定义不一致，必须修正。
