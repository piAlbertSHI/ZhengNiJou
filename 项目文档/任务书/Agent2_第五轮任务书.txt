六、机械耦合和本构重构

每个时间步必须用同一组机械状态满足：

    sigma_a * S_a = sigma_r * S_r

    abs(sum(epsilon_a_i*dx_a)) = abs(sum(epsilon_r_i*dx_r))

要求：

1. `MechanicalCouplingSolver` 输出的 `sigma_a/sigma_r` 直接传入 SMA/SE 相变本构。
2. 删除独立 `stress_profile` 作为本构驱动力。
3. 不通过 `sigma_cap` 截断后继续容忍 Eq.7 大残差。
4. 若材料/几何组合无法同时满足相变和相容，必须判定工况不可行并报告，不能强制 target 相变。
5. 加载、保持、卸载、低载保持四阶段都应有明确机械边界。

硬性机械验收建议：

- Eq.6 scaled residual `< 1e-8`。
- Eq.7 active-stage scaled residual `< 1e-3`。
- 不允许再使用 transient Eq.7 `<5` 作为通过条件。

八、阶段切换时间

停止使用 `[qa,qr,qa,qr]` 权重直接分配阶段时间作为最终方案。

第五轮优先采用 event guarded + maximum duration：

1. Stage 1：
   - SMA 温度/相变达到可驱动条件；
   - SE 相变和应力达到可行加载状态。
2. Stage 2：
   - SE 排热量达到目标，或 SE 温度接近 HHEX/T0。
3. Stage 3：
   - SMA 冷却和 SE 卸载达到相容低载状态。
4. Stage 4：
   - SE 吸热完成，温度接近 Tc/R1 初始状态。

所有事件条件、最大持续时间和实际切换时间必须进入结果。

九、探针要求

保留第四轮 50 samples/stage 的要求，并修正探针语义。

每个实际部件至少保存：

- 动态 internal temperature；
- 流体 inlet temperature；
- 流体 outlet temperature；
- mass flow；
- heat flow；
- active route；
- valve state。

禁止：

- 用固体平均温度冒充流体 outlet；
- 用 reservoir boundary 冒充 internal；
- 用公式热流反推温度探针。

需要新增 probe semantic table，逐个说明：

    probe_name
    physical_location
    measured_state
    unit
    sign_convention
    is_dynamic_state
    source_block

十一、第五轮 hard checks

1. 新主模型明确由 `nixunhuan_solver101_internal.slx` 复制和重组，不是从零新建。
2. 原 `nixunhuan_solver101_internal.slx` 基线和模型文件保持不受破坏。
3. 成熟热容、质量、泵 PI、阀门、HHEX/CHEX、探针和能量审计得到实际复用，不是重新写代理模块。
4. SHEX 由现有成熟热源/热端换热器、管路、缓冲液、阀门和探针等效安排而成，内部结构和已验证参数未被重写。
5. Simulink 不再只有 Clock + 单个全系统 Interpreted MATLAB Function。
6. 两条流体回路都有动态流体状态。
7. SHEX/HHEX/CHEX 入口和出口温度不是常量代理。
8. 每条活动路线满足质量流向和热流方向。
9. 关闭路线不存在非物理热流。
10. Eq.6、Eq.7 在加载和卸载全过程满足严格阈值。
11. 相变推进不依赖 target 相分数。
12. 本构应力和机械审计应力一致。
13. 每阶段和总周期能量残差通过阈值。
14. 动态积分 `Qr/PECC` 与论文对照值误差可解释。
15. 3 cycle 通过后完成 10 cycle，结果不发散。
16. 所有探针语义清楚，图中能看出真实入口/出口温差。
