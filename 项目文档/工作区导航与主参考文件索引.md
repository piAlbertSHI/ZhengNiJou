# 工作区导航与主参考文件索引

## 目录结构

- `gx101r1_R69_remote/`
  - MATLAB、Simulink 源代码和模型。
  - 为避免破坏 MATLAB 同目录函数解析和历史工程依赖，代码暂不按轮次移动。
- `项目文档/任务书/`
  - Agent 执行任务书。新的轮次应新建独立任务书，不再继续扩展一个超长历史文件。
- `项目文档/修改报告/`
  - 每轮修改报告和验证报告。
- `项目文档/研究笔记/`
  - 文献阅读、旧工程理解和本构提取笔记。
- `项目文档/审核分析/`
  - 主控审核、数学/物理问题分析和阶段性结论。
- `热回收驱动弹热冷却系统/`
  - 论文原文，属于只读参考资料。
- `d_2.slx`、`init.m`
  - 早期 SMA/SE 本构原型参考，不是当前系统主模型。
- `.literature_extract/`、`.literature_render/`
  - 文献解析缓存，已由 Git 忽略。
- `gx101r1_R69_remote/outputs*/`、`slprj/`
  - 仿真输出和缓存，已由 Git 忽略。

## 当前第五轮之前的主线文件

以下文件共同组成当前热驱动 ECC Simulink 主线：

1. `gx101r1_R69_remote/Build_HeatDriveECC_Article_Defaults.m`
   - 论文参数、几何参数、输出映射和验证阈值入口。
2. `gx101r1_R69_remote/Build_HeatDriveECC_StageSchedule.m`
   - 当前四阶段时间表。
3. `gx101r1_R69_remote/Build_HeatDriveECC_RouteMatrix.m`
   - 当前阀门和流路布尔矩阵。
4. `gx101r1_R69_remote/Build_HeatDriveECC_Model.m`
   - 创建 `heatdrive_ecc_1d51_fullcycle.slx`。
5. `gx101r1_R69_remote/heatdrive_ecc_1d51_fullcycle.slx`
   - 当前 Simulink 主模型。
6. `gx101r1_R69_remote/HeatDriveECC_SimulinkCoreStep.m`
   - 当前四阶段状态推进核心。第五轮需要重点重构。
7. `gx101r1_R69_remote/Run_HeatDriveECC_Simulink_3Cycle.m`
   - 通用运行、结果整理和探针表生成入口；虽然文件名保留 `3Cycle`，当前支持任意正整数 cycle。
8. `gx101r1_R69_remote/Plot_HeatDriveECC_Temperature_Trends.m`
   - 当前温度和探针绘图入口。
9. `gx101r1_R69_remote/Validate_HeatDriveECC_Simulink_3Cycle.m`
   - 三循环回归验证入口。
10. `gx101r1_R69_remote/Write_HeatDriveECC_Simulink_Report.m`
    - 第四轮验证报告生成器，报告统一写入 `项目文档/修改报告/`。

## 持续维护规则

1. 新任务书放入 `项目文档/任务书/`，每轮单独一个文件。
2. 新修改报告放入 `项目文档/修改报告/`。
3. 主控物理审核放入 `项目文档/审核分析/`。
4. 不把仿真大输出提交到 Git。
5. 不随意移动 `gx101r1_R69_remote/` 中的 MATLAB 函数；如需分包，必须先建立包目录并完成依赖测试。
