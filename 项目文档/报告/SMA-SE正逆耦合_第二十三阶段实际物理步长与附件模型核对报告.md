## 2. 独立积分比较如何进行

读取本机 R2025b 公开 `constant_volume_chamber.ssc`。密闭条件下质量方程给出
`dp/dt = beta * alpha * dT/dt`，代入原始能量式后得到：

```text
dT/dt = Q_H / [V * (rho * cp - T * beta * alpha^2)]
dp/dt = beta * alpha * dT/dt
```

Python 重建与原生值核对过的同一物性表，用 DOP853 进行独立数值积分。采用两档容差、
两档最大步长 .01/.001 s 检查参考解稳定性；不是拿 DOP853 当实验或更真实的物性模型。
MATLAB 原生轨迹和参考解在相同实际时刻对照。审核还检查输入哈希、执行提交、六项配对、
真实本地步长、热流方向、零端口流量、初值和原生密度/内能表一致性。

用三档最大误差的相邻比值计算 `log2(error_h/error_h/2)`，预设一阶识别区间为
0.8 至 1.2。参考解两档差异须小于最细档误差的 1%。这是组件数值行为检查，
不是放松系统质量或能量门禁。
