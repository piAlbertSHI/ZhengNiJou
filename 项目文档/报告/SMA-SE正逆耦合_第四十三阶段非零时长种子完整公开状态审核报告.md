# 第四十三阶段：非零时长种子完整公开状态审核

日期：2026-09-08。范围是 C200 热态迁移方法诊断，不是周期稳态、能量闭合或 Table 4 最终认证。

## 1. 给负责人的结论

首次获得同一物理网络下完整公开状态导入的全观测一步通过结果：
先让诊断种子运行 1 ms，再复制 C200 严格续算供体的全部 73 组公开状态，
初始与一步后各 1474 组观测全部通过原有容差。原先零时长种子的方法不能达到这一结果。

此结论来自实际 MATLAB 仿真、负对照和独立 Python 重算，不仅来自对象赋值成功或 MATLAB 退出 0。
全部观测没有逐位相同，且未运行新物理网络或长周期，因此仍不允许把诊断输出当作生产恢复点。
C200 原始结果及 OP 不变，仍是唯一冻结主线参考。

## 2. 新假设与隔离对照

此前单热容试验中的种子先运行过一步，复杂模型中的种子起止时间相同。
本轮单独控制这一差异，未修改私有 OP 字段，也未猜测求解器打包索引。

| 受体 / 供体 | 求解器公开值复制 | 实际续算温度 | 意义 |
|---|---|---|---|
| 都运行过 1 ms | 340 改为 400 | 400 K | 前轮正对照，复制影响物理输出 |
| 都为零时长 | 0 改为 0 | 340 K | 温度日志虽不同，公开求解器记录尚不是对应温度 |
| 零时长受体 / 运行过 1 ms 的供体 | 0 改为 400 | 340 K | 真正的 400 K 记录也不能使该受体的实际温度改变 |

两次新增隔离试验中的普通积分器 7.25 改为 8.25 均生效。
改变 Simscape 初始化目标的负对照均被严格恢复检查拒绝，未将检查改成 warning 或 none。
因此本次证据指向零时长受体的执行状态差异，不支持“所有公开赋值都无效”的笼统结论。

## 3. 整机试验如何执行

使用 C200 归档物理模型及固定物理参数，保留此前两个 PI 误差滤波器等价状态空间表示，
所以并不声称整个 Simulink 图字节不变。实际源文件提交为
`27f5d61259995781fcdfd26873800cefa3af3ef0`。

从已严格续算的诊断供体读取 2000.001 s 的 73 组公开记录；其本身禁止生产恢复，来源仍由 C200 哈希链固定。
先在独立诊断种子中设置 196 个目标，于 2000 s 核对初始状态，再运行至 2000.001 s。
这些初始目标来自供体所在的严格参考时刻，种子的 1 ms 轨迹本身不宣称是 C200 连续解。
只有随后完整导入公开记录并通过参考比较的试验臂，才获得本报告限定的一步通过结论。

分别执行 72 组非网络状态复制和 73 组完整状态复制，两臂均续算到 2000.002 s。
保持 Simscape 目标开关、ode3、1 ms 步长、局部 Backward Euler 和 accelerator 不变。
供体文件及内存对象未改写；所有复制按完整块路径与状态名匹配，再核对形状和时间戳。

| 指标 | 72 组非网络对照 | 73 组完整复制 |

比较包括 161 组模型信号、1240 组原生物理量和 73 组内部记录。
时间网格严格匹配 `[2000.001, 2000.002]`，完整参考网格为 `[2000, 2000.001, 2000.002]`。
每个通道门槛仍为 `1e-10 + 1e-11 * max(abs(reference), abs(actual))`，未放宽。
最大归一化误差须不超过 1；完整复制臂最大值约 0.00828。
该最大项为热端换热器 HotSinkMass/Q 的一步值，绝对差约 1.422e-12 W。

196 个初始化目标已从 seed_native 原始文件独立核对其初始样本、单位及严格参考来源。
所有完整复制输入均与供体逐位匹配；输出的部分舍入差异被保留，未标为逐位复现。
全量 CSV 共 5896 行，即两臂 × 1474 组 × 两个样本。
236 项 Python 回归测试通过，包括供体必须真实运行、零时长读回不等于物理恢复和容差/逐位区别的负对照。
