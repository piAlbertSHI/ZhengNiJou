# round36：v50/v51 对数闭合、审计分层与下一步控制架构

日期：2026-09-26

## 1. 本轮目标

本轮不导入 C200，不保存生产 checkpoint，不进入 20-cycle、outer solve、敏感性或 paired
Table 4。目标是验证 Stage4 端点黏度闭合是否为流量偏差的结构性来源，并检查审计器是否把
工具契约错误误判为物理失败。

## 2. v50 诊断包的处理

v50 首次启动在 preflight 因字符串闭合模式尚未进入旧数值 override 校验而拒绝，未启动仿真。
修复后 v50b 完成了 10 s 双臂运行，但离线审计发现对数闭合的分母接入了 `mu_out-mu_in`，
而不是 `log(mu_out)-log(mu_in)`。两臂闭合残差约 `0.9958 Pa s`，因此 v50b 明确标记
`REJECTED_DO_NOT_RESUME.txt`，禁止作为证据、初始化源或恢复源。

## 3. 代码与审计修正

提交 `43bec65 Fix Stage4 logarithmic closure denominator audit` 修正了实际 Simulink 拓扑：

- 对数差分块直接接收两端的 `log(mu)` lookup 输出；
- 分子仍为两端指数黏度之差；
- 增加绝对值与单位元安全分母，在端点相等时回退到算术闭合；
- Build 审计检查块类型、端口和所有关键直连关系；
- 候选分析器固定物性参考黏度，并对常量信号返回未定义相关性而非 NaN。

首次复核还发现控制体审计器的 endpoint producer allowlist 没有包含执行提交 `43bec65`，
导致外部 worktree 被错误拒绝。该 allowlist 已按精确 commit 修正并加入回归测试；没有放宽为
任意短前缀或任意实验目录。

## 4. v51 结果

v51 使用修正后的 `43bec65`，从 v47 观测源启动，Stage2/Stage4 Kp 分别为 `-126/-50`，
Stage4 使用 `logarithmic_endpoint`，执行约 7276 s 后自然退出，MATLAB exit code 为 0。
未导入 C200，未保存生产状态。

控制体基础审计：204/204 初始坐标、局部库存、源端口和两臂端点能量通过；两臂端点残差约
`3.8e-10 J`。Stage4 对数公式残差为 `1.73e-18 Pa s`，公式门禁通过。

两臂 Stage4 末窗口结果一致到报告精度：平均流量约 `0.00330279 kg/s`，RMS 相对误差约
`6.666%`，最大绝对相对误差约 `11.226%`，积分质量误差约 `+3.219%`，反向流比例为 0。
因此 Stage4 flow gate=false，`seed_eligible=false`、`outer_solve_eligible=false`、
`paired_table4_eligible=false`。

压力 A/B 范围门禁和液压功诊断通过；17/17 Stage4 观测探针和 1 ms 网格通过；9.84--9.90 s
未发现偶奇交替模式。控制动态分类仍为 `low_gain_slow_tracking_bias`。

压力审计总字段中的 `provenance_gate=false` 是因为其上游 flow-and-inventory gate=false，
不是压力范围或液压功失败；这些子门禁均独立记录为 true，避免把流量失败错误归因到压力探针。

## 5. 高层判断与后续

对数端点闭合没有解决低频流量偏差，但它排除了此前的公式接线错误。下一步不再把闭合式、Kp、
温度边界和状态恢复混在一次试验中。先基于 Stage4 探针建立“前馈静态偏差、温度测点延迟、
PI 积分/anti-windup、执行器压力权威量”的因果分解；再选择一个结构修改方案做新的独立 10 s
双臂包。只有该包同时满足控制动态、输运质量、压力、局部库存和端点能量门禁，才恢复 20-cycle
资格。

本轮不宣称 `validated`、`reproduced` 或 strict Table 4 reproduction。
