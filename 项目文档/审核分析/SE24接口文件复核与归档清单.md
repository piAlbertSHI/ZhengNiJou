## 复核边界

本清单只针对右侧 SE 的 Stage 2 / Stage 4 穿流换热接口。左侧 SMA 的 Stage 1 / Stage 3 暂不纳入本轮修改判断。

本轮原则：

- 不新增并列 `.slx` 主模型。
- 不把简化 51 节点 MATLAB 步进模型误认为成熟 Simscape 流路接口。
- 主程序目录只保留当前主线代码；旧轮次脚本和报告继续留在 `归档`。
- 已归档旧映射函数不得再进入当前 SE 2/4 主链。

## B. SE 2/4 接口运行步骤

责任人复核时应按下面链路理解，不要从 `Run_HeatDriveECC_EighthRound_Simulink_Cycles.m` 开始判断成熟 SE 2/4 接口。

1. 准备模型  
   `Build_nixunhuan_solver101_internal.m` 调用 `Build_Simulink_Exchange_Model.m`，确认当前模型为 `heatdrive_ecc_coupled_se21.slx`，中心核心为 `SE`，内部温度输出变量为 `Tx21_internal`。

2. 准备 runtime  
   `Create_Simulink_Exchange_Runtime.m` 创建 `runtime`，记录当前模型路径、热端/冷端/管路状态、压力缓存、checkpoint 目录等。这个 runtime 必须跨 Stage 2 / Stage 4 连续传递。

3. 准备外部 SE 温度 state  
   `Run_Simulink_Exchange_Hook.m` 输入的 `state_in.T` 当前必须为 21 节点一维轴向温度向量。接口直接传给 Simulink 的 `solver_T_init_21_internal`，不再进行圆薄板 51/101 映射。

4. Stage 2 运行  
   `stage_name = 'hold_exchange'`。  
   `Resolve_Exchange_Stage_Config.m` 设置：
   - `L_valve = [1 1 1 0 0 0]`
   - `flow_path_name = 'chex_to_se_to_hhex'`
   - 物理流路：`CHEX / cold-side buffer -> V1 -> SE21 -> V3 -> HHEX / hot sink`
   - 温度写回：开启。

5. Stage 2 输出写回  
   `Run_Simulink_Exchange_Hook.m` 运行 Simulink 后读取 `Tx21_internal`，提取 SE 入口/出口、HHEX/CHEX 和流量探针，将结果写入 `state_out` 与 `runtime_out.stage2_T_x_21_state`。

6. Stage 4 运行  
   `stage_name = 'cooldown_exchange'`。  
   `Resolve_Exchange_Stage_Config.m` 设置：
   - `L_valve = [0 0 0 1 1 1]`
   - `flow_path_name = 'hhex_to_se_to_chex'`
   - 物理流路：`HHEX / hot-side buffer -> V4 -> SE21 -> V6 -> CHEX / cold return`
   - 温度写回：开启。

7. Stage 4 输出写回  
   `Run_Simulink_Exchange_Hook.m` 读取 `Tx21_internal`，更新 `state_out` 与 `runtime_out.stage4_T_x_21_state`，并写回冷端/CHEX 相关 runtime 状态。

## F. 当前接口状态

接口层已经收敛为 21 节点一维轴向 SE 状态：

- `exchange_backend_kind` 默认是 `simulink_axial_21`。
- `Build_Simulink_Exchange_Params.m` 对 `state_in.T` 执行 21 节点硬校验。
- `Run_Simulink_Exchange_Hook.m` 直接写入 `solver_T_init_21_internal`，读取 `Tx21_internal`，并写回 `stage2_T_x_21_state` / `stage4_T_x_21_state`。
- `Run_Simulink_Exchange_Hook.m` 在加载模型后，会临时隔离左侧孤立副本 `SMA`、`SHEX` 内部的 `To Workspace` 变量名，避免和活跃 SE/HHEX 记录变量冲突；该步骤不保存模型、不改变内部流路。
- 探针变量仍有 `sma_hold_inlet_fluid_temp_out`、`sma_hold_outlet_fluid_temp_out` 等 `sma_*` 名称，但当前中心核心已经改为 `SE`。

## G. 后续归档和修改规则

1. 主模型只允许继续使用 `heatdrive_ecc_coupled_se21.slx`。

3. 简化 eighth-round 51 节点文件暂不删除，作为参考保留，但不得作为 SE 2/4 成熟接口验收入口。
4. 已归档旧映射函数不得恢复到 SE 2/4 主链，除非明确回退到旧圆薄板验证任务。
5. 生成物只进 `gx101r1_R69_remote\outputs` 或 `slprj`，不纳入主程序文件分类。
