# 第四轮结果数学物理审核与第五轮修复依据

## 审核结论

第四轮已经实现可重复的四阶段时间序列、51+51 温度场、探针记录和 3/10 cycle 绘图，但当前结果仍属于“单块 MATLAB 状态机在 Simulink 时间轴中运行”的原型。

当前模型不能证明 SHEX、HHEX/THE、CHEX/RHE 流体线路已经真实连通，也不能证明动态热量和论文功率闭合。第五轮必须重组成熟热流体网络，并接入机械耦合和能量审计。

重要路线纠偏：这些热流体状态、泵阀、冷热端质量/热容、HHEX/CHEX、管路和探针不需要从头设计。`nixunhuan_solver101_internal.slx` 及其构建主线已经具有经过验证的成熟实现。第四轮问题的直接原因是新建了简化 `heatdrive_ecc_1d51_fullcycle.slx`，却没有把 SMA/SE 接回成熟模型。

第五轮应复制并重组 `nixunhuan_solver101_internal.slx`，保留成熟流体部件，只替换圆薄板专属热对象、增加 SMA/SE 51 点接口和机械耦合。SHEX、HHEX/CHEX、阀门、管路和探针均应优先采用现有成熟部件或同类副本，通过论文流路重新安排系统角色与连接拓扑，而不是重新设计。

## 为什么换热器和出入口温度基本不变

问题不只是线路阀门未打开，而是目前没有真正的流体线路状态。

当前 `heatdrive_ecc_1d51_fullcycle.slx` 只有：

1. Simulink Clock；
2. 一个 `Interpreted MATLAB Function`；
3. 一个输出记录块。

`HeatDriveECC_SimulinkCoreStep.m` 内部使用 route 布尔量决定是否将 SMA/SE 温度向预设边界温度松弛。它没有为管路、泵、SHEX、HHEX、CHEX 建立独立质量、热容、流量和入口到出口的输运方程。

当前探针中：

- `SHEX_in`、`SHEX_out`、`SHEX_internal_hot`、`SHEX_internal_fluid` 是固定 `Th+5`、`Th` 或二者平均值。
- `THE_SMA`、`THE_SE`、`HHEX_internal`、`HHEX_out` 是固定 `T0=308 K`。
- `RHE_in`、`CHEX_internal`、`CHEX_in` 是固定 `Tc=288 K`。
- `SMA_HTF_out` 实际记录的是 `mean(T_a)`，不是流体出口温度。
- `SE_HTF_out` 实际记录的是 `mean(T_r)`，不是流体出口温度。

因此这些曲线不变化是当前赋值逻辑的直接结果，不能用来判断真实管路是否连通。

## 当前四阶段路线及物理判断

### Stage 1：`sma_heat_load`

当前路线：

- SHEX -> SMA 开启；
- SMA pump 开启；
- SE 与 HHEX/CHEX 流体路线关闭；
- 机械加载标记开启。

合理物理路线应为：

`SHEX 热侧/热源 -> SHEX 工作流体出口 -> SMA 通道入口 -> SMA 通道出口 -> SHEX 工作流体入口`

SE 流体支路应隔离，但 SMA 对 SE 的机械耦合必须实时成立。

当前问题：

- SMA 吸热探针约 `17.32 J/stage`，但第 10 cycle 的 SMA 显热增加约 `105.19 J`，还伴随约 `36.01 J` 的相变分数变化量。
- 热输入远小于状态能量变化，能量不闭合。
- SE 在无流体换热时固定升温 35 K，来自 `35*rxi_r` 的经验项，不是由 `Delta h/cp` 和机械功自然计算。
- `xM_a/xM_r` 被目标值限制，机械相容不是相变结果的唯一约束。

### Stage 2：`se_reject_heat`

当前路线：

- SHEX -> SMA 仍开启；
- SE -> HHEX/THE 开启；
- SMA、SE pump 均开启；
- 机械耦合标记关闭，但应力保持高位。

合理物理路线应为：

- SMA 处于高温、高载保持状态。优先采用隔离/绝热保持；只有论文或系统设计明确要求时才继续通过 SHEX 维持。
- `SE 出口 -> HHEX/THE 入口 -> HHEX/THE 出口 -> SE 入口`。
- 机械连接必须保持高载约束，不能仅因相变阶段结束而把耦合概念关闭。

当前问题：

- `Q_shex` 为负，说明 stage 2 中 SMA 正向 SHEX 放热，与“SHEX 提供热量”的标签冲突。
- HHEX 内部和出口被固定为 308 K，没有动态热容和流体回路。
- 第 10 cycle 的 HHEX 接热约 `8.59 J`，但 SE 显热只下降约 `3.61 J`，且没有完整流体/换热器储能解释。

### Stage 3：`sma_cool_unload`

当前路线：

- HHEX/THE -> SMA 开启；
- SE 流体线路关闭；
- 机械卸载标记开启。

合理物理路线应为：

`HHEX/THE 工作流体出口 -> SMA 通道入口 -> SMA 通道出口 -> HHEX/THE 工作流体入口`

SE 流体支路隔离，SMA 冷却引发的机械回复必须实时卸载 SE。

当前问题：

- SMA 向 HHEX 放热约 `17.67 J`，但 SMA 显热下降约 `101.54 J`，并伴随约 `36.01 J` 的反向相变变化量，能量严重不闭合。
- SE 固定降温 35 K，仍由经验相变温度项直接产生。
- Eq.7 瞬态归一化残差最大 `3.8947`，最大位移残差 `0.012 m`。该误差不能因为阶段终点残差接近零而判为合格。

### Stage 4：`se_absorb_heat`

当前路线：

- CHEX/RHE -> SE 开启；
- SE pump 开启；
- SMA 流体线路隔离。

合理物理路线应为：

`CHEX/RHE 冷负载侧 -> SE 通道入口 -> SE 通道出口 -> CHEX/RHE 冷负载侧`

需要明确“RHE/CHEX 入口和出口”是以 SE 为参照还是以冷负载为参照，避免温度和热流符号混乱。

当前问题：

- CHEX/RHE 内部和入口被固定为 288 K，仅出口根据 `Q_rhe/100` 人为偏移。
- 第 10 cycle 的 RHE 吸热约 `8.59 J`，而 SE 显热增加约 `3.61 J`，缺少流体和换热器能量状态。
- 冷端曲线变化小不是线路已经正确，而是大部分探针被定义为无限恒温边界。

## 机械与本构问题

1. Eq.6 力平衡通过 `sigma_a=(Sr/Sa)*sigma_r` 构造，因此残差接近零只是代数赋值结果。
2. `mechanical_coupling` 计算一个相容应力，但 `update_phase` 使用另一个独立 `stress_profile` 驱动相变。
3. 同一个时间步内，机械审计应力和本构驱动应力不一致。
4. 相容应力被 `sigma_cap_r` 截断后产生较大 Eq.7 残差。
5. `route_and_targets` 直接提供 `target_a/target_r`，相变速率又被目标值限制，导致相变结果被阶段目标预设。

第五轮必须在每个时间步用同一组 `sigma_a/sigma_r/epsilon_a/epsilon_r/xM_a/xM_r` 同时满足本构、Eq.6 和 Eq.7。

## 热学与能量问题

1. 固体温度方程使用经验 `h_sma=9`、`h_se=8`、`cond=0.06`，没有显式对应 `hA/(m cp)` 和 `alpha/dx^2`。
2. 热流使用独立经验系数 `5 W/K`，与温度更新系数无对应关系。
3. SMA 相变温度项使用 `-1.5*rxi_a`，SE 使用 `35*rxi_r`，没有统一从 `Delta h/cp` 推导。
4. 动态 `Q_shex/Q_the/Q_rhe` 与固体显热、潜热、机械功不闭合。
5. `Qh/Qa/Qr/PECC/etaECC` 被论文公式结果复制到每个 Simulink 样本，不是动态积分结果。
6. `Qh` 又由目标 `PECC=P_H-P_PSC` 反推，存在以目标输出反标热源的循环定义。
7. 四阶段时间按 `[qa,qr,qa,qr]` 权重分配，没有论文直接依据，也没有事件完成度依据。

## 第五轮优先修复顺序

1. 建立真实的两条流体回路及动态入口/出口温度。
2. 建立 SHEX/HHEX/CHEX 独立热容或明确无限边界语义。
3. 统一机械耦合应力与相变驱动应力，消除 Eq.7 瞬态失配。
4. 用质量、比热、潜热、机械功和流体焓差构建每阶段能量闭合。
5. 去除 target 相分数和经验 35 K/1.5 K 相变温度项。
6. 用事件条件或经物理时间常数验证的持续时间切换阶段。
7. 最后再比较论文 `qa/qr/Qr/PECC`，不能先复制论文结果作为动态输出。
