# 正逆耦合 101 流路与加载备忘录

更新日期：2026-06-22

## 0. 当前基线

本轮已退回成熟 101 Simulink 基线：

- 当前主模型：`gx101r1_R69_remote\nixunhuan_solver101_internal.slx`
- 已归档的错误模型备份：`归档\2026-06-22_退回101流路基线\heatdrive_ecc_1d51_eighth_round.slx.bak`

后续修改必须先以 101 模型为流路母版理解，不再从错误的四支路独立闭环模型继续改。

## 1. 最重要的纠错

SE 侧不是两个互不相通的独立闭环：

- 错误理解：Stage 2 是 `SE -> HHEX -> SE`，Stage 4 是 `CHEX -> SE -> CHEX`。
- 正确理解：Stage 2 和 Stage 4 是同一条 101 穿流路径的两个方向。

正确 SE 流路必须是：

```text
Stage 2: CHEX 出发 -> 流经 SE -> 流入 HHEX
Stage 4: HHEX 出发 -> 流经 SE -> 流入 CHEX
```

因此，原 101 模型的中心核心如果把 SMA 材料参数替换为 SE 材料参数，就已经天然对应完整的 SE Stage 2 / Stage 4 换热过程。

## 2. 原 101 流路与 SE 阶段的映射

原 101 的 `hold_exchange` 语义是：

```text
cold-side buffer -> V1 -> 101 节点核心材料 -> V3 -> hot sink
```

把 101 中心核心从 SMA 参数替换为 SE 参数后，它就是正逆耦合系统的 Stage 2：

```text
CHEX / cold-side buffer
  -> 入口阀
  -> SE 101 节点换热核心
  -> 出口阀
  -> HHEX / hot sink
```

物理意义：

- SE 已经被 SMA 执行器加载，处于高应力、高温、马氏体方向状态。
- 来自 CHEX 侧的流体进入 SE，吸收 SE 的相变放热和显热。
- 出口流体进入 HHEX，把热量排到热端/环境端。
- 这个阶段的目标是让 SE 放热，不是让 CHEX 形成闭环。

原 101 的 `cooldown_exchange` 语义是：

```text
hot-side buffer -> V4 -> 101 节点核心材料 -> V6 -> CHEX / cold end
```

把 101 中心核心从 SMA 参数替换为 SE 参数后，它就是正逆耦合系统的 Stage 4：

```text
HHEX / hot-side buffer
  -> 入口阀
  -> SE 101 节点换热核心
  -> 出口阀
  -> CHEX / cold end
```

物理意义：

- SE 已经在 Stage 3 卸载并降温，处于低温吸热能力状态。
- 来自 HHEX 侧的流体流经低温 SE 后被冷却。
- 被冷却的流体进入 CHEX，与冷负载换热，形成有效制冷。
- 这个阶段的目标是把冷量送到 CHEX，不是让 HHEX 形成闭环。

## 3. SMA 侧流路

SMA 侧目前理解保持如下：

```text
Stage 1: SHEX / 废热源 -> SMA 执行器 -> 返回 SHEX / 废热源回路
Stage 3: HHEX / T0 热汇 -> SMA 执行器 -> 返回 HHEX / T0 热汇回路
```

Stage 1 的物理意义：

- 热源流体加热 SMA。
- SMA 从马氏体向奥氏体转变并收缩。
- SMA 收缩通过机械连接加载 SE。
- SE 从奥氏体向马氏体转变，温度升高。

Stage 3 的物理意义：

- HHEX/T0 流体冷却 SMA。
- SMA 从奥氏体向马氏体恢复。
- 机械驱动力下降，SE 卸载。
- SE 从马氏体向奥氏体逆转变，温度下降，准备 Stage 4 制冷。

## 4. 四阶段完整加载与流体顺序

完整单级正逆耦合循环应按以下顺序推进。

### Stage 1: SMA 热驱动加载 SE

```text
SHEX -> SMA -> SHEX
SE 流体侧不做穿流换热，或只保留内部热容状态。
```

状态变化：

```text
SMA: M -> A，升温，收缩
SE : A -> M，被加载，升温
```

必须审计：

- SMA 热源入口/出口温度。
- SMA 吸热量。
- SMA 马氏体分数下降。
- SE 马氏体分数上升。
- 力平衡残差 `sigma_SMA*S_SMA - sigma_SE*S_SE`。
- 位移相容残差 `epsilon_SMA*L_SMA - epsilon_SE*L_SE`。

### Stage 2: SE 放热到 HHEX

```text
CHEX -> SE -> HHEX
```

状态变化：

```text
SE 保持加载高应力状态，向流体放热。
流体从 CHEX 侧进入，经过热的 SE 后升温，最后进入 HHEX。
```

必须审计：

- SE 入口来自 CHEX。
- SE 出口进入 HHEX。
- `T_SE_out > T_SE_in` 应在主要放热区间成立。
- HHEX 得到正的热输入。
- CHEX 不能被当成此阶段的热量接收终点。

### Stage 3: SMA 冷却卸载 SE

```text
HHEX / T0 -> SMA -> HHEX / T0
SE 流体侧不做穿流换热，或只保留内部热容状态。
```

状态变化：

```text
SMA: A -> M，降温，驱动力下降
SE : M -> A，卸载，降温
```

必须审计：

- SMA 冷却入口/出口温度。
- SMA 放热到 HHEX/T0。
- SMA 马氏体分数上升。
- SE 马氏体分数下降。
- SE 温度出现卸载降温趋势。
- 机械耦合残差仍闭合。

### Stage 4: SE 向 CHEX 提供冷量

```text
HHEX -> SE -> CHEX
```

状态变化：

```text
SE 处于卸载低温状态。
流体从 HHEX 侧进入，经过冷的 SE 后降温，最后进入 CHEX。
CHEX 再与冷负载换热，得到有效制冷量。
```

必须审计：

- SE 入口来自 HHEX。
- SE 出口进入 CHEX。
- `T_SE_out < T_SE_in` 应在主要制冷区间成立。
- CHEX 得到冷量，不是 HHEX 得到冷量。
- 冷负载热量通过 CHEX 被带走。

## 5. 和文献阀门时序的关系

2024 中文 Simulink 文献把完整运行细分成 6 个阀门区间：

```text
t0-t1:   V1
t1-t2:   V1 + V4
t2-t3:   V1 + V5
t3-t4:   V2 + V3
t4-t5:   V2 + V5
t5-t0':  V2 + V4
```

这个六区间可以理解成四个物理阶段的细分控制，而不是推翻四阶段：

- `V1` 主导 SMA 热源加热。
- `V2 + V3` 主导 SMA 冷却/PEMFC 热管理旁路。
- `V4` 主导 SE 与环境热汇/HHEX 交互。
- `V5` 主导 SE 与冷端/CHEX 交互。

在程序实现上，可以先保留四阶段主调度，再在 Stage 1/2 和 Stage 3/4 内部补充文献阀门细分；但无论怎样细分，SE 侧两个核心穿流方向不能改变：

```text
Stage 2: CHEX -> SE -> HHEX
Stage 4: HHEX -> SE -> CHEX
```

## 6. 后续接入 Stage 1 和 Stage 3 的原则

SE Stage 2/4 应优先复用 101 成熟流路：

```text
101 hold_exchange     -> SE Stage 2: CHEX -> SE -> HHEX
101 cooldown_exchange -> SE Stage 4: HHEX -> SE -> CHEX
```

Stage 1/3 不应破坏这条 SE 母流路，而应作为 SMA 执行器侧新增热驱动/冷却过程接入：

```text
Stage 1: SHEX 加热 SMA，并通过机械耦合更新 SE 的加载状态
Stage 3: HHEX/T0 冷却 SMA，并通过机械耦合更新 SE 的卸载状态
```

接入策略：

1. 保留 101 模型的热端、冷端、CHEX、HHEX、泵、阀、探针和 101 节点穿流结构。
2. 先把 101 中心核心参数替换为 SE，作为 Stage 2/4 的真实流路求解对象。
3. 新增 SMA 执行器热状态模块，用 SHEX/HHEX 两条 SMA 侧流路推进 Stage 1/3。
4. 在每个时间步由 SMA 与 SE 的力平衡、位移相容、本构方程求解耦合应力，而不是给 SE 强行赋加载曲线。
5. Stage 1/3 只更新机械耦合和材料状态，不把 SE 侧错误接成独立闭环。
6. Stage 2/4 只通过 101 穿流换热更新 SE 温度场和两端热量，不把 CHEX/HHEX 当成简单边界常数。

## 7. 后续验收硬条件

任何后续修改必须满足：

- 主程序目录只保留一个 `.slx` 主模型，当前为 `nixunhuan_solver101_internal.slx`。
- SE Stage 2 的流路报告必须写成 `CHEX -> SE -> HHEX`。
- SE Stage 4 的流路报告必须写成 `HHEX -> SE -> CHEX`。
- 输出探针必须能区分：
  - SE Stage 2 入口温度、出口温度、CHEX 侧入口、HHEX 侧出口。
  - SE Stage 4 入口温度、出口温度、HHEX 侧入口、CHEX 侧出口。
- 不能用后处理把 `Q_CHEX`、`Q_HHEX` 或温度趋势强行改成正确方向。
- 若 Stage 2/4 的入口出口方向不满足本备忘录，直接判定流路错误，不能继续调本构参数。
