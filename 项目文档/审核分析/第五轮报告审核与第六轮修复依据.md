# 第五轮报告审核与第六轮修复依据

生成时间：2026-06-11

## 一、审核结论

第五轮不是验收失败的小偏差，而是暴露出当前模型仍没有形成可用于论文复现的真实正逆耦合系统。它的价值在于定位了失败边界：模型已经从成熟 `nixunhuan_solver101_internal.slx` 复制出第五轮主模型，也建立了 51+51 节点、四阶段调度、探针和机械审计接口；但热源、热汇、冷端、相变、本构、能量审计没有形成物理闭环。

当前第五轮模型的核心问题是：

1. SHEX 没有向 SMA 提供论文量级的热输入。
2. SMA 和 SE 的相变没有推进，机械耦合停留在退化零载状态。
3. 现有能量审计仍有代理计算和强行赋值，不能证明动态能量闭合。
4. 将成熟模型的有限两条支路直接重命名为 SHEX/THE/RHE，会造成热边界语义冲突和 Simscape 求解不稳定。
5. 直接运行 3 cycle 或 10 cycle 已没有意义，必须先做支路级、阶段级、机械级的分层验证。

第六轮总体目标保持不变：在成熟 Simulink 部件基础上，复现论文热驱动弹热冷却器四阶段正逆耦合循环，先获得真实 3 cycle 物理趋势，再做 10 cycle 稳定性检查。第六轮不能接受任何“为了出图或过表格而强行赋值”的结果。

## 二、第五轮失败证据

第五轮报告中的关键失败证据如下：

1. 稳定 1-cycle 审计中：
   - Stage1 `Ta` 只从 308 K 增加到 308.039945 K；
   - `xM_a` 始终为 1；
   - `xM_r` 始终为 0；
   - `SHEX_input_J = 0`；
   - `relative_residual = 3.47153848245893`，远大于 5%。

2. swap-route 试验：
   - 将 SMA Stage1 改走 V4/V5/V6 后，Stage3 在 `SMA_Actuator_MatureLoop/热端换热器/HotPipe` 处发生 nonlinear solver failed to converge；
   - 说明同一成熟热支路跨阶段承担不同物理角色会产生热边界冲突。

3. Stage1 0.02 s 诊断：
   - 修正热边界后 600 s 仍未返回；
   - 这不是正常长仿真，而是求解器卡在刚性/代数/初始化问题上。

4. 当前代码中的审计风险：
   - `Run_HeatDriveECC_FifthRound_Cycles.m` 中 `q_shex = q_sma_hold`，把 SMA 支路焓差直接当作 SHEX 输入；
   - `PECC_dynamic_W = Qr_dynamic_W`，没有从系统能量和论文定义动态计算；
   - 这些写法必须删除或替换为真实测量与积分，不能作为第六轮结果依据。

## 三、数学和物理原因

### 1. 热量量级不对

论文默认参数对应：

- `tau_cycle = 1.59447513812155 s`；
- `Qh = 44.2322866573 W`；
- 单周期热输入量约为 `Qh * tau_cycle = 70.5 J`；
- Stage1 持续约 `0.394085153676306 s`，若热量主要在 Stage1 输入，则 Stage1 等效功率应为约 `179 W` 量级。

第五轮 1-cycle 中 SMA 支路只得到约 `0.29 J` 量级的流体能量，且 `SHEX_input_J = 0`。这个热量不足以把 SMA 从 308 K 加热到论文的 `Th = 340.412070 K`，因此不会触发明显 M->A 相变。

### 2. 机械耦合处于退化零载

第五轮机械核初始化为：

- SMA martensite fraction `xM_a = 1`；
- SE martensite fraction `xM_r = 0`；
- 初始应力由 Eq.6/Eq.7 算得为零载。

如果 Stage1 没有真实 SHEX 加热，`xM_a` 不会下降，SE 也不会被加载，`xM_r` 不会上升。此时 Eq.6/Eq.7 residual 为 0 只是因为力和位移都没有发生，不是物理通过。

第六轮必须把“非退化机械耦合”作为硬门槛：

- Stage1：`xM_a` 应从 1 降低，目标变化量接近论文 `delta_xM_a`；
- Stage1：`xM_r` 应从 0 增加，SE 被加载；
- Stage3：`xM_a` 应回升，SE 被卸载；
- Eq.6/Eq.7 residual 必须在非零应力、非零相变状态下通过。

### 3. 成熟支路不能被任意重命名为热源或热汇

成熟 solver101 的两条流体支路是经过验证的，但它们有原始的热边界、缓冲液、HotPipe/ColdPipe、热端/冷端质量语义。第五轮把 hold/cooldown branch 直接重命名为 SHEX/THE/RHE 后，出现两个问题：

1. 设置初始温度不能代替持续热源或热汇；
2. 同一类管路/换热器跨阶段承担相反热角色时，容易产生热边界冲突和求解器不收敛。

第六轮应改为四个物理角色明确的支路实例：

- `SMA_SHEX`：热源支路，只负责 Stage1 给 SMA 输入废热；
- `SMA_THE`：环境热汇支路，只负责 Stage3 冷却 SMA；
- `SE_THE`：环境热汇支路，只负责 Stage2 让 SE 放热；
- `SE_RHE`：冷端吸热支路，只负责 Stage4 让 SE 从冷负载吸热。

这些支路仍应复制成熟部件实现，不是从零设计；但每个支路必须有独立的热边界语义、入口/出口探针和能量审计，不能靠同一支路在不同阶段变换物理身份。

### 4. 能量审计不能使用代理量

动态能量闭合必须来自 Simulink/Simscape 实际信号：

- 固体显热：由 51 节点温度积分；
- 潜热：由相分数变化率积分；
- 机械功：由应力、应变、体积或力位移积分；
- 流体换热：由真实 `m_dot * cp * (T_in - T_out)` 积分；
- SHEX/HHEX/CHEX/RHE 边界能量：由对应热源/热汇/冷负载端口或边界储能变化积分。

禁止：

- 用 `q_sma_hold` 直接冒充 `Q_shex`；
- 用论文常数直接填充动态结果；
- 用 `PECC_dynamic = Qr_dynamic` 冒充电力输出；
- 用固定相分数 target 强迫相变；
- 用固定温度或平均固体温度冒充入口/出口探针。

## 四、四阶段流路循环逻辑

第六轮应按以下物理流路实现和审计。

### Stage 1: `sma_heat_load`

物理目标：废热源 SHEX 加热 SMA，SMA 由马氏体向奥氏体转变并通过机械耦合加载 SE。

推荐流路：

```text
SHEX 热源/热流体出口
  -> SMA_SHEX 泵/阀
  -> SMA actuator 沿长度 51 节点换热通道
  -> SHEX 热流体入口
  -> SHEX 热源/缓冲液重新加热
```

预期符号和趋势：

- `m_dot_SMA_SHEX > 0`；
- `T_SHEX_to_SMA_in > T_SMA_from_SHEX_out`，热流体在 SMA 中降温；
- `Q_SHEX_boundary > 0`，废热进入工作流体；
- `Q_SMA_from_fluid > 0`，SMA 得热；
- `mean(Ta)` 从 308 K 明显上升，接近论文 `Th` 的方向；
- `xM_a` 下降，`xM_r` 上升；
- SE 不接任何流体支路，SE 温升来自近绝热加载。

### Stage 2: `se_reject_heat`

物理目标：SE 在高载状态向环境热汇 THE/HHEX 放热。

推荐流路：

```text
THE/HHEX 环境侧流体出口
  -> SE_THE 泵/阀
  -> SE refrigerant 沿长度 51 节点换热通道
  -> THE/HHEX 环境侧流体入口
  -> THE/HHEX 向 T0 环境放热
```

预期符号和趋势：

- `m_dot_SE_THE > 0`；
- 以流体进入 SE 为入口，`T_SE_THE_out > T_SE_THE_in`，流体从 SE 吸热；
- HHEX/THE 对环境放热为正；
- `mean(Tr)` 从加载后的高温下降；
- `xM_r` 应主要保持高载相态，不应被人为重置；
- SMA 支路关闭，SMA 处于高温/高载滞留或按论文定义保持。

### Stage 3: `sma_cool_unload`

物理目标：环境热汇 THE/HHEX 冷却 SMA，SMA 逆转变并卸载 SE，SE 近绝热降温。

推荐流路：

```text
THE/HHEX 环境侧流体出口
  -> SMA_THE 泵/阀
  -> SMA actuator 沿长度 51 节点换热通道
  -> THE/HHEX 环境侧流体入口
  -> THE/HHEX 向 T0 环境放热
```

预期符号和趋势：

- `m_dot_SMA_THE > 0`；
- `T_SMA_THE_out > T_SMA_THE_in`，流体从 SMA 吸热；
- `mean(Ta)` 下降；
- `xM_a` 上升；
- `xM_r` 下降，SE 因卸载产生弹热降温；
- SE 流体支路关闭。

### Stage 4: `se_absorb_heat`

物理目标：低载低温 SE 从冷负载 RHE/CHEX 吸热，产生制冷量。

推荐流路：

```text
RHE/CHEX 冷负载侧流体出口
  -> SE_RHE 泵/阀
  -> SE refrigerant 沿长度 51 节点换热通道
  -> RHE/CHEX 冷负载侧流体入口
  -> RHE/CHEX 从冷负载补热
```

预期符号和趋势：

- `m_dot_SE_RHE > 0`；
- 以冷负载流体进入 SE 为入口，流体向 SE 放热，因此冷负载流体出口温度应低于入口温度；
- `Q_RHE_to_SE > 0`；
- `mean(Tr)` 从低温回升；
- `xM_r` 低载状态保持或按论文回到 R1；
- SMA 支路关闭。

## 五、第六轮改进方向

第六轮应采取“先支路、再阶段、再整循环”的验证方式：

1. 保留 `nixunhuan_solver101_internal.slx` 和第五轮失败模型，不覆盖。
2. 新建第六轮模型或构建脚本，优先从第五轮脚本继续，但要隔离四个支路角色。
3. 复制成熟部件形成 `SMA_SHEX`、`SMA_THE`、`SE_THE`、`SE_RHE` 四个独立支路实例。
4. 每条支路先用固定固体温度做 0.02 s、0.1 s、full-stage 预检，确认流量、入口/出口温差、边界能量符号。
5. 机械本构先用规定温度轨迹离线验证，再接入 Simulink。
6. 删除所有代理审计和强行赋值。
7. 只有 Stage1 full 能把 SMA 明显加热并推进相变，才允许进入 1-cycle。
8. 只有 1-cycle 能量和相变趋势通过，才允许进入 3-cycle。
9. 3-cycle 通过后再做 10-cycle 稳定性检查。

第六轮真正进展的判据不是“程序跑完”，而是：

- 四条支路均有真实动态入口/出口温差；
- SHEX 输入达到论文量级；
- SMA/SE 相分数按四阶段方向变化；
- 非退化 Eq.6/Eq.7 通过；
- 每阶段能量残差可解释并逐步接近阈值；
- 所有图和表来自实际仿真信号。
