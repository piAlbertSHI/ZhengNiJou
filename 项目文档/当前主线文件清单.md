# 当前主线文件清单

更新日期：2026-06-22

## 主模型

- `gx101r1_R69_remote\heatdrive_ecc_coupled_se21.slx`
  当前唯一 Simulink 主模型。后续正逆耦合热驱动 ECC 拓扑必须先以该成熟 101 流路为母版理解和修改。

## 运行入口

- `Run_HeatDriveECC_EighthRound_Simulink_Cycles.m`
  Simulink 连续循环运行入口。
- `Run_HeatDriveECC_EighthRound_MatlabCore.m`
  MATLAB core step 轻量检查入口，不替代 Simulink 联合仿真。
- `Validate_HeatDriveECC_EighthRound_Physics.m`
  当前物理审查、绘图和报告入口。

## 参数与拓扑配置

- `Build_HeatDriveECC_Article_Defaults.m`
  原文材料、系统与目标量参数来源。
- `Build_HeatDriveECC_EighthRound_Defaults.m`
  当前主线默认参数、输出映射和输出目录。
- `Build_HeatDriveECC_EighthRound_BranchRoles.m`
  四阶段支路角色定义。
- `Build_HeatDriveECC_RouteMatrix.m`
  四阶段流路矩阵。
- `Build_HeatDriveECC_StageSchedule.m`
  四阶段时间表。
- `Build_HeatDriveECC_EighthRound_Simulink_Model.m`
  加载并配置当前唯一 Simulink 模型，不再生成旧模型。

## 51 节点动态推进

- `Initialize_HeatDriveECC_EighthRound_State.m`
  初始化 SMA、SE 和支路状态。
- `Initialize_HeatDriveECC_EighthRound_Branches.m`
  初始化四条换热支路。
- `Initialize_HeatDriveECC_FiniteVolumeBranchState.m`
  单支路有限体积初始状态。
- `HeatDriveECC_EighthRound_CoreStep.m`
  单步状态推进主函数。
- `HeatDriveECC_EighthRound_SimulinkStep.m`
  Simulink MATLAB Function 调用的状态推进封装。
- `HeatDriveECC_EighthRound_StateToOutput.m`
  将内部状态和审计量展开为输出向量。
- `HeatDriveECC_AxialFVBranchStep51.m`
  51 节点流体支路换热推进。
- `HeatDriveECC_AxialSolidThermalStep51.m`
  SMA/SE 51 节点轴向固体热推进。
- `HeatDriveECC_BranchStorageJ.m`
  支路储热计算。
- `HeatDriveECC_ConstitutiveCompatibilityStep51.m`
  SMA 与 SE 的 51 节点本构兼容推进。

## 成熟换热桥接保留文件

- `Build_Simulink_Exchange_Params.m`
  复用原成熟流路中的泵压、阀门、换热器参数桥接思想；当前 SE 2/4 接口输入为 21 节点一维轴向温度状态。
- `Build_Simulink_Exchange_Model.m`
  成熟流路模型构建器，供理解和重建 `heatdrive_ecc_coupled_se21.slx` 使用。
- `Run_Simulink_Exchange_Hook.m`
  SE Stage 2/4 单阶段 Simulink 调用入口。当前 backend 为 `simulink_axial_21`，直接传入/读出 `Tx21_internal`，不再经过 51/101 映射。
- `Create_Simulink_Exchange_Runtime.m`
  当前默认指向 `heatdrive_ecc_coupled_se21.slx`。
- `Resolve_Exchange_Stage_Config.m`
  当前默认指向 `heatdrive_ecc_coupled_se21.slx`，用于阶段配置解析。
- `GlobalXi_Checkpoint_To_Simulink_State.m`
  换热桥接兼容旧 checkpoint 结构的辅助函数。
