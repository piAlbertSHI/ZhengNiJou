二、系统物理逻辑必须先理清

本系统不是“外部压力驱动圆薄板”，也不是“单独文章公式计算器”。正确系统是：

1. 热源来自 PSC 废热或等效 SHEX。
   - SHEX 提供热流体，使 SMA actuator 从环境温度附近升温到驱动温度 `Th`。
   - 论文中 `Qh = Qa = G*A_PSC - P_PSC - QL`，频率 `nu = Qh/(ma*qa)`。若本轮暂不完整接入 PSC 电模型，必须用论文 Eq.23/Eq.24 给出等效 SHEX 热源设定和来源说明。

2. SMA actuator 是热驱动执行器。
   - 初始状态 A1：`T_a ≈ T0`，马氏体分数 `xM_a ≈ 1`。
   - 被 SHEX 加热后，从 A1 经 A2/A3 到 A4，马氏体向奥氏体转变，发生回复/收缩变形。
   - 该变形通过机械耦合向 SE 提供应力和位移。

3. SE refrigerant 是被 SMA 驱动的弹热制冷体。
   - 初始状态 R1：`xM_r ≈ 0`，无外力，奥氏体。
   - 被 SMA 加载后，从 R1 到 R2，目标是 `Delta xM_r ≈ 1`，发生应力诱导马氏体转变并升温。
   - 与 THE 换热时，从 R2 到 R4，向 THE 放出相变热/显热。
   - 卸载和 RHE 换热后回到 R1，向 RHE 提供冷量。

4. 机械耦合是 SMA 和 SE 的核心，不是可选后处理。
   - 力平衡：`sigma_a * S_a = sigma_r * S_r`。
   - 位移相容：`abs(integral(epsilon_a dx over La)) = abs(integral(epsilon_r dx over Lr))`。
   - 若 51 节点近似均匀，则退化为论文 Eq.7：`abs(epsilon_a*La)=abs(epsilon_r*Lr)`。
   - Simulink 中必须实时计算或准静态求解 `sigma_a, sigma_r, epsilon_a, epsilon_r, xM_a, xM_r`，并记录 Eq.6/Eq.7 残差。

5. 热交换器和阀门决定四阶段边界条件。
   - 论文结构包含 SHEX/SHE、SMA、SE、RHE、THE、pump、两个三通阀、四个止回阀、piston 和管路。
   - SMA 属于第一回路：SHEX <-> SMA <-> THE。
   - SE 属于第二回路：THE <-> SE <-> RHE。
   - 当前成熟工程已有“冷/热双通道避免加载后和卸载后换热污染”的思想，可以保留；但必须新增 SHEX，并按论文重排阀门/闸门位置和每阶段流路。

三、SMA 和 SE 模块划分决策

第四轮采用“拆分物理子模块 + 顶层耦合子系统”的方案，不做一个黑盒模块，也不做完全独立的两个模块。

建议 Simulink 层级：

    HeatDrivenECC_1D51
      StageScheduler
      ValveAndFlowController
      SHEX_SourceLoop
      THE_SinkLoop
      RHE_RefrigerantLoop
      SMA_Actuator_1D51
      SE_Refrigerant_1D51
      MechanicalCouplingSolver
      EnergyAndEquationAudit
      OutputLogger

理由：

1. SMA 和 SE 的材料参数、初始相态、热边界和相变方向不同，必须拆分成两个清晰子模块。
2. SMA 和 SE 又通过 Eq.6/Eq.7 强耦合，不能各自独立求解后再事后修正。
3. 顶层 `MechanicalCouplingSolver` 统一处理符号、力平衡、位移相容和应力分配，避免把正负号散落到热模块或材料模块中。
4. 顶层 `ValveAndFlowController` 统一处理 SHEX/THE/RHE 与双通道换热，避免冷热通道状态互相污染。

四、完整四阶段 Simulink 执行要求

本轮必须在一个 Simulink 仿真时间轴内完成 3 个 cycle。允许为调试写单阶段测试模型或脚本，但最终验收入口必须是全周期模型。

四阶段建议命名和物理动作如下：

1. `sma_heat_load`
   - 阶段状态：A1 -> A4，R1 -> R2。
   - SMA 流路：SHEX 热流体打开，SMA 与 SHEX 换热；THE 冷却支路关闭。
   - SE 流路：SE 与 THE/RHE 换热支路关闭或保持隔离；机械加载 active。
   - 物理趋势：
     - `T_a` 上升；
     - `xM_a` 下降；
     - SMA 收缩/回复变形增大；
     - `sigma_r` 上升；
     - `xM_r` 上升，目标接近 1；
     - SE 由于加载出现升温趋势。

2. `se_reject_heat`
   - 阶段状态：R2 -> R4，SMA 保持 A4 或高温受控状态。
   - SE 流路：SE 与 THE 打开，向 THE 放热。
   - SMA 流路：SMA 不应被错误接到 T0 冷却支路；需要保持热态或按论文流路维持。
   - 物理趋势：
     - SE 热量流向 THE；
     - `T_r` 降向 T0 侧；
     - `xM_r` 应维持高马氏体或按本构小幅演化，不应提前回到奥氏体；
     - SMA 不应在本阶段被卸载。

3. `sma_cool_unload`
   - 阶段状态：A4 -> A1，SE 从高载向卸载过程过渡。
   - SMA 流路：THE/T0 回路打开，SMA 被 THE 侧流体冷却。
   - SE 流路：SE 与 THE/RHE 换热支路关闭或保持隔离；机械卸载 active。
   - 物理趋势：
     - `T_a` 下降；
     - `xM_a` 上升回到马氏体；
     - `sigma_r` 下降；
     - SE 发生逆相变趋势并降温。

4. `se_absorb_heat`
   - 阶段状态：SE -> R1。
   - SE 流路：SE 与 RHE 打开，从冷端/RHE 吸热并提供制冷。
   - SMA 流路：SMA 保持冷态或与 T0 支路隔离/受控。
   - 物理趋势：
     - RHE 热量流向 SE；
     - 冷端有正的制冷量；
     - `xM_r` 回到接近 0；
     - 结束时 SMA/SE 应接近下一 cycle 初始状态。

六、阀门、流路和换热通道重构要求

新增 SHEX 后，不能再直接套用旧模型的 `hold_exchange/cooldown_exchange` 两阶段流路。

第四轮必须建立清晰的 valve/route matrix，建议用结构体或表格输出：

必须满足：

1. SMA 第一回路：
   - 加热时接 SHEX；
   - 冷却时接 THE/T0；
   - 两条流体路径不得在数组/水箱状态上错误共用，除非明确模拟 THE 共同热容。

2. SE 第二回路：
   - 放热时接 THE；
   - 吸热时接 RHE；
   - 放热后的热流体状态不得污染吸热阶段的冷端流体状态。

3. THE 是论文中的 sink heat exchanger at T0。
   - THE 可以作为共享环境热汇，但不能让 SMA 冷却回路和 SE 放热回路在数值上无控制混合。
   - 如果用同一个 THE 热容，必须显式写出能量平衡和混合规则。
   - 第一版更稳妥的做法是保留成熟工程“双通道防污染”思想：THE_SMA_branch 和 THE_SE_branch 分开审计，必要时再通过同一个 T0 边界汇合。

4. RHE 是制冷输出端，不是旧冷端任意水箱。
   - 必须输出 RHE 侧吸热量、入口/出口温度、冷量积分。

5. SHEX 是本轮新增核心模块。
   - 必须输出 SHEX 输入热流、SMA 吸热量、SHEX 入口/出口或等效边界温度。

   - stage 3 `mean(sigma_r)` 下降；

   - cycle 结束时 `mean(xM_r)` 回到低值，接近 R1；

   - THE 在 stage 2 接收 SE 热量；
   - THE/T0 在 stage 3 冷却 SMA；
   - RHE 在 stage 4 被 SE 吸热，形成冷量；

二、必须实现的公式

机械耦合约束：

    sigma_a * S_a = sigma_r * S_r                         (Eq. 6)
    abs(epsilon_a * L_a) = abs(epsilon_r * L_r)           (Eq. 7)

论文一维 SMA/SE 轴向本构：

    epsilon_a = epsilon_T_a * Delta_xM_a - sigma_a / E_m_a    (Eq. 8)
    epsilon_r = epsilon_T_r * Delta_xM_r + sigma_r / E_m_r    (Eq. 9)

制冷体 SE 全相变约束：

    Delta_xM_r = 1                                           (Eq. 10)

由 Eq. 6-10 推得的 SMA 马氏体分数变化：

    Delta_xM_a =
        (L_r/L_a) * (epsilon_T_r/epsilon_T_a)
        + [ (L_r/L_a) + (S_r/S_a)*(E_m_r/E_m_a) ]
          * sigma_r / (E_m_r * epsilon_T_a)                  (Eq. 11)

Clausius-Clapeyron 关系：

    d_sigma_r,a / dT = C_r,a                                  (Eq. 12)

加载阶段执行器 SMA 约束：

    C_M_a * [T_h - T_As_a - Delta_xM_a*(T_Af_a - T_As_a)]
        = sigma_a_ld
        = (S_r/S_a) * sigma_r_ld                              (Eq. 13)

卸载阶段执行器 SMA 约束：

    C_A_a * [T_0 - T_Ms_a - Delta_xM_a*(T_Mf_a - T_Ms_a)]
        = sigma_a_uld
        = (S_r/S_a) * sigma_r_uld                             (Eq. 14)

最小驱动温差：

    T_h - T_0 ≈
        (S_r/S_a) * Delta_sigma_r / C_A_a
        + T_As_a - T_Ms_a
        + Delta_xM_a * (T_Af_a - T_As_a + T_Ms_a - T_Mf_a)    (Eq. 15)

单周期单位质量热量：

    q_a =
        c_p_a * (T_h - T_0) * (1 - eta_hr)
        + Delta_h_a * Delta_xM_a
        + w_ld_r * mu                                         (Eq. 16)

    q_r =
        Delta_h_r
        + w_uld_r
        - c_p_r * (T_0 - T_c) * (1 - eta_hr)                  (Eq. 17)

其中：

    mu = (L_r/L_a) * (S_r/S_a) * (rho_r/rho_a)

热功率和制冷功率：

    Q_a = m_a * nu * q_a                                      (Eq. 18)
    Q_r = m_r * nu * q_r                                      (Eq. 19)
    P_ECC = Q_r                                               (Eq. 20)
    eta_ECC = P_ECC / (G * A_PSC)                             (Eq. 21)

如果第二轮需要暂时只做 ECC 而不做完整 PSC 耦合，仍必须保留 `G*A_PSC`、`Q_h=Q_a`、`nu=Q_h/(m_a*q_a)` 的接口，方便后续接入 PSC。

3. SMA_Actuator_LumpedModel.m
   作用：执行 SMA 的 lumped/1D 材料和热模型。

   建议公式：

   - alpha(xi) = alpha_A + xi * (alpha_M - alpha_A)
   - eps_tr(xi) = eps_L * xi
   - K_a = E(xi) * A_a / L_a

   - F = sigma * A_a

   注意符号：
   - 必须在代码注释和报告中定义清楚：actuator 输出正力对应 refrigerant 正压力加载。
   - 如果内部应力符号与现有圆薄板压力符号相反，必须在 coupling 层统一，不要把符号散落到各处。

4. Solve_SMA_Actuator_Refrigerant_Coupling.m
   作用：求执行 SMA 与制冷 SMA 圆薄板之间的机械耦合。

   输入建议：
   - actuator_state
   - actuator_params
   - refrigerant_checkpoint
   - refrigerant_params/grid
   - coupling_options
   - stage mode: heating_load 或 cooling_unload

   输出建议：
   - pressure_MPa
   - force_actuator_N
   - force_refrigerant_N
   - displacement_actuator_m
   - displacement_refrigerant_proxy_m
   - residual_force_N
   - residual_displacement_m
   - residual_norm
   - solver_status

   机械约束第一版：
   - F_a = F_r
   - delta_a = transmission_ratio * delta_r

   其中：
   - F_r = P_eq * A_effective_plate
   - A_effective_plate 默认可取 pi * R^2，也允许 options 覆盖；
   - delta_r 可先取圆薄板中心挠度 w_center，或现有 balance 中的 deflection/volume proxy；
   - 若使用 w_center，需要先确认 GlobalXi 的 w 索引方向和符号。

   求解策略：
   - 优先用 quasi-static bisection/secant。
   - 未必要追求快，goal 模式不考虑时间成本，先追求正确和可解释。
   - 对候选 pressure，调用或包装现有 GlobalXi 求解器得到 refrigerant 响应。
   - 如果直接按候选压力反复完整求解太慢，也可以先实现近似 compliance 模型，但必须在报告中标注。

5. Run_CoupledSMA_LoadUnload_Stage.m
   作用：替代原阶段 1/3 的固定压力加载/卸载。

   对每个时间步执行：
   - 更新 actuator 热状态；
   - 根据 actuator 当前 T/xi/free strain 求可用力；
   - 调用耦合求解器得到 refrigerant 等效压力；
   - 用该压力推进 GlobalXi 圆薄板状态；
   - 记录 actuator_trace、pressure_trace、coupling_trace、refrigerant checkpoint。

   阶段 1 heating_load：
   - actuator 被热源/废热加热；
   - actuator 由马氏体向奥氏体转变并收缩；
   - refrigerant 被加载，目标是 A -> M，温度升高；
   - pressure 应整体上升或达到平台。

   阶段 3 cooling_unload：
   - actuator 被冷却或断热回冷；
   - actuator 回复，输出力降低；
   - refrigerant 卸载，目标是 M -> A，温度降低；
   - pressure 应整体下降到接近 0。

6. Run_CoupledSMA_SingleStage_Cycles.m
   作用：单级热驱动正逆耦合系统主入口。

   可以参考 Run_GlobalXi_Simulink_Cycles.m 的结构，但四阶段改为：
   - stage 1: actuator_heat_load
   - stage 2: hold_exchange，内部仍传给 Resolve_Exchange_Stage_Config.m 使用原 stage name
   - stage 3: actuator_cool_unload
   - stage 4: cooldown_exchange，内部仍传给 Resolve_Exchange_Stage_Config.m 使用原 stage name

   注意：
   - 阶段 2/4 仍然使用 Run_Simulink_Exchange_Hook。
   - 经过 Simulink 的温度场仍用 Build_GlobalXi_Checkpoint_From_Exchanged_T 回写。
   - 仍然调用 Build_GlobalXi_Restart_Balance_Checkpoint 做 restart balance。
   - actuator state 也要在每个阶段结束时存入 runtime/result，不能丢失。

7. Build_CoupledSMA_SingleStage_Report.m
   作用：汇总新增耦合系统的报告。

   必须包含：
   - actuator 热输入；
   - actuator 温度范围；
   - actuator xi 范围；
   - actuator 输出机械功；
   - refrigerant 接收等效机械功；
   - pressure max/min；
   - 阶段 2 热端放热；
   - 阶段 4 冷端吸热；
   - 泵功；
   - 系统 COP；
   - coupling residual 统计；
   - 所有能量审计是否有限。

8. Validate_CoupledSMA_SingleStage_Smoke.m
   作用：最小烟测。

   要求：
   - n_cycles = 1；
   - 阶段时间可以短一些；
   - 能跑完整四阶段；
   - 输出 result mat 文件；
   - 输出 summary struct；
   - 关键量 finite；
   - 不破坏原 Remote_RunCase。

六、单级系统的物理流程要求

实现出来的单级热驱动循环应满足以下物理顺序：

1. 执行 SMA 加热加载
   - actuator 吸收热源热量；
   - actuator 发生热驱动相变并输出机械作用；
   - refrigerant 被加载；
   - refrigerant 的等效压力上升；
   - refrigerant 温度应出现加载升温趋势。

2. 制冷 SMA 热端放热
   - 保持高载或近似高载；
   - 调用现有 Simulink hold_exchange；
   - refrigerant 热量排到热端；
   - Simulink 输出温度回写到 GlobalXi。

3. 执行 SMA 冷却卸载
   - actuator 降温或失去热驱动力；
   - coupling pressure 降低；
   - refrigerant 卸载；
   - refrigerant 温度应出现卸载降温趋势。

4. 制冷 SMA 冷端吸热
   - 调用现有 Simulink cooldown_exchange；
   - refrigerant 从冷端/冷负载吸热；
   - 冷端输出按现有报告符号约定统计。

十一、总体判断

本任务的正确实现路线是：

先把执行 SMA 做成 MATLAB 层 lumped 热驱动源，通过力-位移耦合生成制冷圆薄板的等效压力；保留现有 Simulink 四阶段换热、泵压、冷热端、冷负载、checkpoint 和能量审计体系。这样可以最快把“单级正逆耦合热驱动”跑通，同时为后续双级热回收系统保留清晰扩展路径。

十二、赋予 Agent2 的自主决策权

你在执行本任务时拥有一定程度的自主决策权。原则是：只要不破坏现有成熟外压驱动流程，不删除原始文件，不绕开物理审计，并且能让单级热驱动系统更快形成可运行闭环，就可以自行选择具体实现细节。

   - 再接入 GlobalXi 阶段 1/3。
   - 最后接入 Simulink 阶段 2/4。

必须暂停并向主控用户说明的情况：

   对 NaN/Inf、压力越界、节点数量不匹配、checkpoint 缺字段等情况，要用明确 error message 或 warning。

5. 不要为了美观做大重构。
   本任务重心是把单级热驱动闭环跑通，而不是整理整个历史工程。

6. 尽量保持 ASCII 代码注释。
   中文说明可以写在 `.md` 或 `.txt` 报告中。MATLAB 函数内注释建议用简短英文，减少编码问题。

十七、最终交付判断

如果你只能完成一部分，优先级如下：

1. 保留原工程可用。
2. actuator lumped 模型可独立验证。
3. coupling 求解器可输出可审计 pressure。
4. 阶段 1/3 可由 actuator 生成 pressure trace。
5. 完整四阶段跑通。
6. 报告、文档、Git 提交完整。

完整成功的定义：

    新增入口可以运行 1 个完整单级热驱动四阶段周期；
    结果中包含 actuator、coupling、pressure、refrigerant、exchange 和 energy summary；
    原外压驱动流程仍保留；
    Git 有清晰提交历史；
    最终文本修改报告清楚说明实现、验证和限制。
