Agent2 的任务书：将现有圆薄板单级系统改进为单级热驱动正逆耦合系统

一、总目标

你要在当前成熟工程 gx101r1_R69_remote 的基础上，实现一个“单级热驱动 SMA 正逆耦合弹热制冷系统”的第一版可运行仿真。

现有成熟工程本质是：

    单个 SMA 圆薄板制冷体 + 外加压力加载/卸载 + Simulink 四阶段流体换热

你的目标是把它改成：

    热驱动执行 SMA actuator + 机械耦合 + SMA 圆薄板制冷体 refrigerant + 现有 Simulink 热端/冷端换热

核心变化是：阶段 1 和阶段 3 不再使用预设压力斜坡作为机械驱动，而是由执行 SMA 的加热/冷却相变产生力和位移，再通过机械耦合转换成制冷 SMA 圆薄板的等效压力或等效边界。

阶段 2 和阶段 4 暂时继续复用现有 Simulink 换热平台。

1. 不要推翻 gx101r1_R69_remote。
   它已经有成熟的泵压、阀控、冷热端、冷负载、数据覆盖传入、accelerator 运行、并行远程运行、checkpoint 和验证体系。

   保留 Run_GlobalXi_Simulink_Cycles.m 的原行为。新增 coupled single-stage 入口。

   d_2.slx 只作为早期概念参考。

4. 第一版不要急着重搭 Simulink。
   actuator 的热驱动过程先在 MATLAB 层实现为 lumped/1D 模型。Simulink 仍然只负责制冷 SMA 圆薄板的阶段 2/4 换热。

   不要把 actuator 参数、传动比、面积比、热源温度、加热功率等写死在函数内部。

四、建议新增的文件

优先新增这些文件，尽量减少对原文件的侵入：

1. Build_CoupledSMA_Default_Options.m
   作用：构造单级热驱动系统默认参数。

   建议字段：
   - options.n_cycles
   - options.outputs_dir
   - options.refrigerant
   - options.actuator
   - options.coupling
   - options.stage_schedule
   - options.exchange_options
   - options.solver_options
   - options.validation_options

   exchange_options 尽量复用 Remote_RunCase.m 里的成熟配置，包括：
   - model_path = nixunhuan_solver101_internal.slx
   - exchange_backend_kind = simulink_directional_101
   - cold_load_mode
   - buffer_follow_sink_enabled
   - cold_end_topology_mode
   - flow_control_mode
   - simulation_mode
   - solver / RelTol / AbsTol / MaxStep
   - hotflush_stop_time_s
   - coldflush_stop_time_s
   - flush_volume_target_ratio

2. Initialize_SMA_Actuator_State.m
   作用：初始化热驱动执行 SMA 的 lumped 状态。

   推荐 state 字段：
   - T_K
   - xi
   - epsilon
   - sigma_Pa
   - force_N
   - displacement_m
   - heat_input_J
   - latent_J
   - mechanical_work_J
   - time_s

   初始物理含义：
   - actuator 初始为低温马氏体倾向，xi 接近 1；
   - refrigerant 初始应与现有 GlobalXi 基线一致，通常作为低压初态。

3. SMA_Actuator_LumpedModel.m
   作用：执行 SMA 的 lumped/1D 材料和热模型。

   建议 action 接口：
   - 'constitutive'
   - 'phase_target'
   - 'thermal_step'
   - 'force_at_displacement'
   - 'free_strain'
   - 'stiffness'

   第一版可以使用简化相变律：
   - 加热时，若 T 从 A_s 到 A_f，xi 从 1 降到 0；
   - 冷却时，若 T 从 M_s 到 M_f，xi 从 0 升到 1；
   - 可加入 tau_xi 松弛，避免 xi 突跳；
   - 后续再加应力修正 Clausius-Clapeyron。

   建议公式：
   - E(xi) = E_A + xi * (E_M - E_A)
   - alpha(xi) = alpha_A + xi * (alpha_M - alpha_A)
   - eps_tr(xi) = eps_L * xi
   - K_a = E(xi) * A_a / L_a
   - sigma = E(xi) * (epsilon - eps_tr(xi) - alpha(xi) * (T - T_ref))
   - F = sigma * A_a

   注意符号：
   - 必须在代码注释和报告中定义清楚：actuator 输出正力对应 refrigerant 正压力加载。
   - 如果内部应力符号与现有圆薄板压力符号相反，必须在 coupling 层统一，不要把符号散落到各处。

4. Solve_SMA_Actuator_Refrigerant_Coupling.m
   作用：求执行 SMA 与制冷 SMA 圆薄板之间的机械耦合。

   输入建议：
   - actuator_state
   - actuator_params
   - refrigerant_checkpoint
   - refrigerant_params/grid
   - coupling_options
   - stage mode: heating_load 或 cooling_unload

   输出建议：
   - pressure_MPa
   - force_actuator_N
   - force_refrigerant_N
   - displacement_actuator_m
   - displacement_refrigerant_proxy_m
   - residual_force_N
   - residual_displacement_m
   - residual_norm
   - solver_status

   机械约束第一版：
   - F_a = F_r
   - delta_a = transmission_ratio * delta_r

   其中：
   - F_r = P_eq * A_effective_plate
   - A_effective_plate 默认可取 pi * R^2，也允许 options 覆盖；
   - delta_r 可先取圆薄板中心挠度 w_center，或现有 balance 中的 deflection/volume proxy；
   - 若使用 w_center，需要先确认 GlobalXi 的 w 索引方向和符号。

   求解策略：
   - 优先用 quasi-static bisection/secant。
   - 未必要追求快，goal 模式不考虑时间成本，先追求正确和可解释。
   - 对候选 pressure，调用或包装现有 GlobalXi 求解器得到 refrigerant 响应。
   - 如果直接按候选压力反复完整求解太慢，也可以先实现近似 compliance 模型，但必须在报告中标注。

5. Run_CoupledSMA_LoadUnload_Stage.m
   作用：替代原阶段 1/3 的固定压力加载/卸载。

   对每个时间步执行：
   - 更新 actuator 热状态；
   - 根据 actuator 当前 T/xi/free strain 求可用力；
   - 调用耦合求解器得到 refrigerant 等效压力；
   - 用该压力推进 GlobalXi 圆薄板状态；
   - 记录 actuator_trace、pressure_trace、coupling_trace、refrigerant checkpoint。

   阶段 1 heating_load：
   - actuator 被热源/废热加热；
   - actuator 由马氏体向奥氏体转变并收缩；
   - refrigerant 被加载，目标是 A -> M，温度升高；
   - pressure 应整体上升或达到平台。

   阶段 3 cooling_unload：
   - actuator 被冷却或断热回冷；
   - actuator 回复，输出力降低；
   - refrigerant 卸载，目标是 M -> A，温度降低；
   - pressure 应整体下降到接近 0。

6. Run_CoupledSMA_SingleStage_Cycles.m
   作用：单级热驱动正逆耦合系统主入口。

   可以参考 Run_GlobalXi_Simulink_Cycles.m 的结构，但四阶段改为：
   - stage 1: actuator_heat_load
   - stage 2: hold_exchange，内部仍传给 Resolve_Exchange_Stage_Config.m 使用原 stage name
   - stage 3: actuator_cool_unload
   - stage 4: cooldown_exchange，内部仍传给 Resolve_Exchange_Stage_Config.m 使用原 stage name

   注意：
   - 阶段 2/4 仍然使用 Run_Simulink_Exchange_Hook。
   - 经过 Simulink 的温度场仍用 Build_GlobalXi_Checkpoint_From_Exchanged_T 回写。
   - 仍然调用 Build_GlobalXi_Restart_Balance_Checkpoint 做 restart balance。
   - actuator state 也要在每个阶段结束时存入 runtime/result，不能丢失。

7. Build_CoupledSMA_SingleStage_Report.m
   作用：汇总新增耦合系统的报告。

   必须包含：
   - actuator 热输入；
   - actuator 温度范围；
   - actuator xi 范围；
   - actuator 输出机械功；
   - refrigerant 接收等效机械功；
   - pressure max/min；
   - 阶段 2 热端放热；
   - 阶段 4 冷端吸热；
   - 泵功；
   - 系统 COP；
   - coupling residual 统计；
   - 所有能量审计是否有限。

8. Validate_CoupledSMA_SingleStage_Smoke.m
   作用：最小烟测。

   要求：
   - n_cycles = 1；
   - 阶段时间可以短一些；
   - 能跑完整四阶段；
   - 输出 result mat 文件；
   - 输出 summary struct；
   - 关键量 finite；
   - 不破坏原 Remote_RunCase。

六、单级系统的物理流程要求

实现出来的单级热驱动循环应满足以下物理顺序：

1. 执行 SMA 加热加载
   - actuator 吸收热源热量；
   - actuator 发生热驱动相变并输出机械作用；
   - refrigerant 被加载；
   - refrigerant 的等效压力上升；
   - refrigerant 温度应出现加载升温趋势。

2. 制冷 SMA 热端放热
   - 保持高载或近似高载；
   - 调用现有 Simulink hold_exchange；
   - refrigerant 热量排到热端；
   - Simulink 输出温度回写到 GlobalXi。

3. 执行 SMA 冷却卸载
   - actuator 降温或失去热驱动力；
   - coupling pressure 降低；
   - refrigerant 卸载；
   - refrigerant 温度应出现卸载降温趋势。

4. 制冷 SMA 冷端吸热
   - 调用现有 Simulink cooldown_exchange；
   - refrigerant 从冷端/冷负载吸热；
   - 冷端输出按现有报告符号约定统计。

十一、总体判断

本任务的正确实现路线是：

先把执行 SMA 做成 MATLAB 层 lumped 热驱动源，通过力-位移耦合生成制冷圆薄板的等效压力；保留现有 Simulink 四阶段换热、泵压、冷热端、冷负载、checkpoint 和能量审计体系。这样可以最快把“单级正逆耦合热驱动”跑通，同时为后续双级热回收系统保留清晰扩展路径。

十二、赋予 Agent2 的自主决策权

你在执行本任务时拥有一定程度的自主决策权。原则是：只要不破坏现有成熟外压驱动流程，不删除原始文件，不绕开物理审计，并且能让单级热驱动系统更快形成可运行闭环，就可以自行选择具体实现细节。

你可以自主决定：

1. 新增函数的具体命名。
   - 如果本任务书建议的函数名与实际代码结构不完全匹配，可以微调。
   - 但最终必须在报告中列出实际采用的函数名和调用关系。

2. actuator 第一版模型的复杂度。
   - 可以先做 lumped 0D/1D 热模型。
   - 可以先使用线性相变区间模型。
   - 可以先忽略应力对相变温度的修正。
   - 但必须保留接口，方便后续加入 Clausius-Clapeyron 修正。

3. coupling 第一版的位移代理。
   - 可以选择圆薄板中心挠度 `w_center`。
   - 可以选择现有 restart balance 中的 deflection/volume proxy。
   - 可以选择等效线性 compliance 作为临时近似。
   - 但必须在报告中写清楚选用原因、公式、符号约定和误差来源。

4. pressure 推进方式。
   - 可以先生成 pressure profile，再调用现有 loading/unloading 求解器。
   - 也可以实现逐步推进，每步更新 actuator 和 refrigerant。
   - 如果逐步推进侵入太大，可以先采用“actuator 生成等效压力轨迹”的过渡实现。
   - 但最终结果中必须保留 actuator_trace、pressure_trace 和 coupling_trace，不能只留下压力。

5. smoke test 的参数。
   - 可以缩短阶段时间。
   - 可以降低周期数到 1。
   - 可以降低采样点数。
   - 可以临时关闭非必要绘图。
   - 但不能关闭关键物理审计和 NaN/Inf 检查。

6. 调试和验证顺序。
   - 可以先做纯 MATLAB actuator-coupling 单元测试。
   - 再接入 GlobalXi 阶段 1/3。
   - 最后接入 Simulink 阶段 2/4。
   - 不要求一步到位，但最终必须形成完整四阶段运行入口。

必须暂停并向主控用户说明的情况：

1. 发现现有核心文件与任务书描述明显不一致，继续执行会导致大范围重写。

2. Simulink 模型无法加载或 MATLAB 环境缺失关键 toolbox，且无法通过代码侧 workaround 跑通阶段 2/4。

3. 现有 GlobalXi 求解器无法接受任何形式的压力轨迹或 restart checkpoint，导致必须重写核心求解器。

4. 单级热驱动系统只能通过删除物理审计、禁用相变、固定温度或伪造输出才能跑通。

5. coupling residual 长期失控，且无法通过参数调整或更换位移代理改善。
